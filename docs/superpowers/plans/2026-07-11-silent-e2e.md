# E2E 静默模式实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 E2E 测试运行时 Electron 主窗口不显示、不抢焦点、不遮挡用户当前窗口。

**Architecture:** 在主进程新增 `E2E_SILENT=1` 环境变量分支，创建窗口时设置 `show: false` 并跳过 `maximize()`/`focus()`；在 E2E fixture 中默认注入该变量，使所有 E2E 用例自动静默。

**Tech Stack:** Electron, TypeScript, Playwright, Node.js spawn

```ts
const isE2ESilent = process.env.E2E_SILENT === '1'
```

- [ ] **Step 2: Modify BrowserWindow creation to hide window in silent mode**

- [ ] **Step 3: Skip maximize in silent mode**

替换 `electron/main.ts:127` 的 `mainWindow.maximize()`：

```ts
if (!isE2ESilent) {
  mainWindow.maximize()
}
```

### Task 2: Enable `E2E_SILENT` in the E2E fixture

**Files:**
- Modify: `e2e/fixtures/electron.ts:134-141`

- [ ] **Step 1: Inject `E2E_SILENT=1` by default**

在 `e2e/fixtures/electron.ts` 的 spawn `env` 对象中加入 `E2E_SILENT: '1'`：

```ts
env: {
  ...env,
  NODE_ENV: 'test',
  E2E_CONFIG_DIR: testConfigDir,
  E2E_STUDY_LIBRARY_PATH: testLibraryPath,
  E2E_SKIP_PROBE: '1',
  E2E_SILENT: '1',
  TAVILY_API_KEY: tavilyKey || process.env.TAVILY_API_KEY || '',
  ...extraEnv,
}
```

`...extraEnv` 放在最后，允许单个测试通过 `extraEnv` 临时覆盖 `E2E_SILENT`。

- [ ] **Step 2: Typecheck the fixture**

Run: `npx tsc --noEmit`
Expected: PASS with no errors.

- [ ] **Step 3: Commit**

```bash
git add e2e/fixtures/electron.ts
git commit -m "feat(e2e): default E2E_SILENT=1 in fixture"
```
