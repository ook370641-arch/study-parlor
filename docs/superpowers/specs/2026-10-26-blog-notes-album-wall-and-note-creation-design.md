# 博客/笔记专辑墙统一交互与博客对应笔记（2026-10-26）

## 背景与目标

本期合并处理记事板中除「新来源：书籍与阅读器」外的四项需求：

1. 仿照笔记，为博客增加主区专辑墙。
2. 用户可基于当前阅读博客一键创建对应笔记，并用于博客对照。
3. 博客与笔记统一为「无打开内容时显示专辑墙；正文可返回专辑墙并遗忘选中态」。
4. 博客与笔记专辑墙第一行均提供排序和筛选；笔记默认按笔记类型排序。

本期只调整现有博客、笔记和对照文流程，不新增书籍来源、电子书阅读器或 AI 笔记内容生成。

## 现状与约束

- 笔记已有 `NotesWall`、笔记正文返回按钮，以及共享的 `notesCategory` / `notesSortBy` 状态。
- 博客主区无打开文章时目前只有空态；文章列表、筛选、导入和阅读恢复逻辑集中在 `AnthropicBlogPanel`。
- 博客对照挑选器已有为当前博客新建笔记的入口，目标实现应保留「创建后直接放入对照槽」的上下文行为。
- `2026-10-22-notes-album-wall-design.md` 中「主区顶部不再重复工具栏」被本次需求明确替代：笔记专辑墙第一行必须有自己的排序与筛选控件。
- 保留左侧/第二列列表作为快速索引；专辑墙只替换主区空态，不改变现有三栏结构。

## 一、博客专辑墙

### 显示条件

博客主区按现有优先级显示宪法报告、推荐视图或文章阅读器；以上视图均未打开时，用博客专辑墙替代原空态。

- 没有可恢复的文章选中态时，进入博客直接显示专辑墙。
- 存在有效的 `lastAnthropicReaderFile` 时仍按现有逻辑恢复阅读器；文件已失效则显示专辑墙。
- 后台正在检测新文章不影响专辑墙显示，也不阻断卡片点击。

### 卡片内容与数据

- 使用当前 `displayArticles`，与左侧文章列表同源，不新增网络请求或文章数据源。
- 已导入和未导入文章都显示；未导入卡片沿用现有点击导入并打开的流程。
- 卡片采用与笔记墙相近的 3:4 网格封面：有 `imageUrl` 时显示图片，无图时显示来源色占位封面。
- 卡片至少显示标题、来源和发布日期；已导入状态用轻量标记表示。
- 本地宪法报告卡片继续打开现有报告视图。
- 对照模式下点击卡片继续复用现有主文/对照槽路由，不另造打开逻辑。

### 空态与加载

- 文章缓存尚未加载时显示轻量加载态，而不是永久空态。
- 筛选后无结果显示「当前筛选下暂无文章」；可清空筛选。
- 图片加载失败回退到来源色占位封面，不影响标题和点击操作。

## 二、统一专辑墙返回交互

### 博客

- 文章阅读器左上角增加 `← 博客墙`。
- 点击后关闭当前阅读器并回到博客专辑墙。
- 同时清空 `anthropicReaderFilePath`、正文缓存和持久化的 `lastAnthropicReaderFile`，确保切换页面或重启后不会因旧选中态自动重新打开文章。
- 不清除收藏、已读、标注或阅读位置历史；这些不是「文章选中态」。
- 关闭当前文章对应的对照选中态，避免返回墙后仍保留不可见的文章关联。

### 笔记

- 保留正文左上角 `← 笔记墙`，点击后清空 `writingFile` 并显示笔记专辑墙。
- 若 `lastWritingFile` 指向当前笔记，同时清除该持久化选中标记，避免旧笔记被后续恢复逻辑重新选中。
- 返回前沿用现有 dirty 文件保存策略，不因返回墙丢弃未保存内容。

### 列表与主区一致性

- 返回专辑墙后，左侧/第二列不再显示文章或笔记的选中样式。
- 再次点击任一卡片或列表项，正常打开对应内容并重新记录选中态。

## 三、专辑墙第一行排序与筛选

### 笔记专辑墙

第一行放置来源筛选和排序两个控件，与第二列共用同一 store 状态，任一侧修改都立即同步另一侧和专辑墙。

- 来源筛选：`全部 / Anthropic / 网页 / 书籍 / 未知`。
- 排序：`类型 / 最新收录 / 评分`。
- 新增 `source` 排序值，默认排序改为「类型」；已有用户显式保存的排序偏好仍尊重，不强制覆盖。
- 类型顺序固定为 `anthropic → web → book → unknown`，类型内部按 `collected_at` 倒序。
- 「最新收录」保持时间倒序；「评分」保持评分倒序、同分按时间倒序。
- 筛选结果为空时保留工具栏，并显示该分类暂无笔记。

### 博客专辑墙

第一行放置筛选和排序控件，并作用于卡片墙；现有左侧搜索与筛选继续有效，卡片墙展示它们的共同结果。

- 筛选项：`全部 / 已导入 / 各博客来源`，复用现有 `BlogFilter` 语义。
- 排序项：`最新发布 / 最早发布`，默认最新发布。
- 本地宪法报告在使用现有「始终置顶」规则时不随普通文章日期排序；其余文章按 `publishedAt` 排序，缺失日期的文章排尾。
- 排序和筛选只改变展示顺序与结果，不修改文章缓存、收藏或已读状态。

## 四、当前博客一键生成对应笔记

### 统一创建规则

从当前博客创建笔记时统一写入：

- `title`：当前文章标题。
- `url`：当前文章 `source_url`。
- `source`：`anthropic`。
- `rating`：0；`summary` / `highlight`：空字符串；正文：空。
- `collected_at`：创建时间；文件名冲突沿用现有唯一文件名策略。

本期「生成对应笔记」是创建可编辑的空白笔记并建立来源关联，不复制博客正文，也不调用 LLM 自动生成摘要或笔记内容。

### 去重与已有笔记

- 以笔记 `meta.url` 与当前博客 `source_url` 的精确匹配判断对应笔记。
- 已存在对应笔记时不重复创建，直接打开或选中已有笔记。
- 匹配不受当前来源筛选影响，避免笔记被筛选隐藏后误判为不存在。
- 创建期间按钮进入 busy 状态并防止重复提交；失败时保留当前页面并显示错误提示。

### 两个入口的上下文行为

- **博客正文操作区**：增加「生成对应笔记」。创建成功或命中已有笔记后，切换到「写作 → 笔记」并打开该笔记。
- **博客对照挑选器**：保留「＋ 新建」。创建成功或命中已有笔记后，将笔记直接放入当前博客的对照槽，不离开博客正文。
- 两个入口复用同一创建/查找逻辑，避免标题、来源和去重规则分叉。

## 状态与接口调整

- `notesSortBy` 增加 `'source'`，同步更新 store、`StateJson`、默认状态和相关控件类型。
- 博客阅读器的显式「返回墙」需要同步清理持久化选中态；不能把只清运行时状态的现有 `closeAnthropicReader` 直接当作完整实现。
- 笔记创建 IPC 的参数类型需完整传递 `source`，与现有主进程创建能力保持一致。
- 博客墙排序可使用面板内状态；本期不要求持久化博客排序偏好。
- 不为本期新增书籍来源字段或电子书相关状态。

## 验证与验收

### 单元/组件测试

- 笔记类型排序的顺序、组内时间倒序、筛选和旧排序回归。
- 博客墙显示筛选后的文章，有图/无图卡片均可渲染，点击复用打开或导入流程。
- 博客与笔记返回墙后选中态清除；博客持久化恢复标记同步清除。
- 当前博客无对应笔记时创建并写入正确元数据；已有时不重复创建。
- 正文入口创建后打开笔记；对照入口创建后放入对照槽。

### 定向 E2E

- 博客无选中文章 → 专辑墙 → 筛选/排序 → 打开文章 → 返回博客墙 → 不自动恢复旧文章。
- 笔记无选中笔记 → 专辑墙 → 来源筛选/类型排序 → 打开笔记 → 返回笔记墙。
- 当前博客一键创建对应笔记，再次执行不产生重复文件。
- 按变更文件运行定向测试；若新增 E2E spec，先更新 `e2e/source-map.json`。
