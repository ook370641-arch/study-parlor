# 学习页与文章／仓库内容墙列表化设计（2026-11-22）

## 1. 背景与设计结论

记事板条目 `nmwrfxkfxu7oc` 的截图提出七项改动：来源导航对齐、说明弹层遮挡、推荐归入分组、学习主题列表化、文章／仓库支持列表、学习墙版式按钮改为字号，以及保留博客／笔记卡片形态。

本设计采用以下结论：

1. **学习墙固定使用列表**。一行是一个主题，可展开历次学习；报告、对话、图表、寓言、复习等学习专属能力完整保留。
2. **文章与仓库同时支持卡片和列表**。两种形态共用目录分组、排序和文件操作，视图按 root 独立记忆；初始仍沿用当前卡片，避免未经要求改变既有默认视图。
3. **博客、笔记、书籍不改展示形态**。博客和笔记继续使用卡片，书籍沿用现有书架，不增加列表开关。
4. **推荐卡内部样式不变**，但不再组成独立顶部推荐区，而是插入对应分组开头。
5. **学习墙不引入 AI 封面**。列表密度、分组色和层级线替代当前大面积空白轨道卡面，视觉回到旧「点亮灯火」的紧凑感，但不恢复已删除的旧路由和分页。
6. **复用现有 `studyFontSize`**。学习墙右上角的版式切换改为 `− / +`，同时缩放学习第二列、学习墙、主题工作区与正式学习正文；来源列和其他来源不随之变化。
7. **不合并领域交互**。学习主题行与文章文件行可以共享间距、色彩和分组骨架，但不能共用一个强行兼容所有操作的巨型行组件。

本文是后续实现的设计依据。`2026-11-17-learning-source-restructure-design.md` 的学习墙与推荐布局由本文取代，其余学习生命周期约定继续有效；`2026-11-14-writing-album-wall-design.md` 仅追加文章／仓库列表形态，其余存储、封面和删除契约不变。功能落地时再同步两份旧文档的状态与指针。

## 2. 需求映射

| 截图要求 | 设计落点 |
|---|---|
| 「学习」与其他三个来源未对齐 | 四个导航项统一 20px 图标槽、行高、水平内边距；选中边框在所有项中预留，不只在 active 项新增 |
| 分组指南显示后被其他界面遮挡 | 指南与说明弹层 Portal 到 `document.body`，使用顶层浮层与视口碰撞定位 |
| 推荐样式不变，放进不同分组开头 | 分组灵感进入对应组；意外之径进入即将归属的组；推荐策略入口移至学习墙页头 |
| 学习主题用列表更合适 | 主题行 + 可展开 session 列表 + 学习产物操作；取消学习 3:4 卡片和分页 |
| 文章和仓库也支持列表 | 工具栏增加列表／卡片切换，按 `writing` / `repository` 独立持久化 |
| 博客和笔记卡片更合适 | `BlogWall`、`NotesWall` 继续现有 `AlbumCard`，不增加视图切换 |
| 版式按钮改为字体大小 | 学习墙页头改为 `− / +`，复用 `studyFontSize`；换画保留 |
| 字体不影响来源列，影响第二列和正文 | 建立学习字号作用域，来源列保持固定字号；学习第二列、墙、主题正文和正式学习同步缩放 |

「推荐样式不变」指标签、标题、钩子、刷新、加载和错误视觉不变；容器宽度随分组列表自适应，不再维持三列推荐网格。

## 3. 范围与非目标

### 3.1 本次范围

- 学习来源的导航对齐、学习墙列表、分组内推荐、主题展开与 session 产物入口。
- 学习第二列、学习墙、主题工作区和正式学习的字号联动。
- 分组指南与现有说明弹层的层级和定位修复。
- 文章／仓库卡片与列表切换、列表文件行和视图持久化。
- 深色学术模式、报纸模式、双列收起、空态、搜索、异常和窄窗口。
- 既有推荐、归档、报告、对话、图表、寓言、复习、拖拽、删除与封面链路保全。

### 3.2 非目标

- 不恢复旧 `Home`、`StudyLibrary`、`SessionViewer` 或九条分页。
- 不新增学习卡 AI 封面、归档主题视图、状态筛选、session 级分组或多前台会话。
- 不改学习库目录、Markdown 文件格式、分组映射、推荐缓存和 IPC 文件契约。
- 不为博客、笔记、书籍增加列表开关。
- 不改设置中心，不重新设计正式学习对话，只验证既有功能在新入口下可达。
- 不把文章／仓库列表变成学习 session 列表，也不给文件行添加报告、寓言或复习操作。

## 4. 信息架构与领域分工

```text
学习
├─ 来源列：四来源，固定字号，可展开／收起
├─ 学习第二列：分组 → 主题 → 第 N 次学习
└─ 主工作区
   ├─ 学习墙
   │  ├─ 页头、语录、未完成会话
   │  └─ 分组
   │     ├─ 推荐槽（0–2 条）
   │     └─ 主题行 → 可展开 session 行
   └─ 主题工作区：报告 / 对话 / 图表 / 寓言 / 复习

写作
├─ 文章：目录分组 → 文件卡片或文件行
├─ 仓库：目录分组 → 文件卡片或文件行
└─ 笔记：继续现有卡片

博客 / 书籍
└─ 现有卡片、书架、第二列和阅读工作区不变
```

| 能力 | 学习主题行 | 文章／仓库文件行 |
|---|---|---|
| 基本单元 | 主题 | 文件 |
| 主点击 | 打开主题最近报告 | 打开编辑器或预览 |
| 展开内容 | 历次 session 与产物 | 无 |
| 主操作 | 继续、复习、更多 | 封面、删除 |
| 更多操作 | 重命名、归档 | 沿用当前文件操作，不新增学习语义 |
| 媒体 | 分组色条，无封面 | 小封面缩略图或类型渐变 |
| 元数据 | 次数、最近学习、复习状态 | 字数／类型、修改时间、路径 |
| 拖拽 | 卫星引力场换组 | 沿用当前目录树能力，不从文件行新增拖拽 |

## 5. 学习墙页头

页头从左到右保留问候、副标题，右侧依次放置：

1. 推荐策略 `StrategyToggle`，沿用 `v1 → v2 → v3 → v1` 与持久化。
2. 「复习是怎么来的」和「学习图表是怎么来的」两个既有说明入口。
3. 学术模式下的换画按钮。
4. `−` 与 `+` 字号按钮；到达最小／最大档位时禁用。

学习墙不再显示版式切换按钮，但仍响应全局 `briefingTheme`。其他来源与正式学习页的既有控制不因此删除。语录保留在页头下方，未完成会话条保留「继续 / 焚毁」，两条操作均使用现有快照与后台会话逻辑。

页头文案由「从任何一张卡继续夜谈」改为「从任何一行继续夜谈」。

## 6. 分组内推荐

### 6.1 推荐槽组成

每个可见分组的内容顺序固定为：**推荐槽 → 主题行**。推荐槽最多包含两条：

- 当前组的 `GroupRecCard`：始终插入它所属的分组。
- `WildCardRecCard`：全部分组视图插入「默认」组开头；单组筛选视图插入当前组开头。

意外之径只是推荐来源，不创建新分组。点击推荐进入 `PreStudyModal` 时显式携带目标 `groupId`：全部分组视图为默认组，单组视图为当前组；用户完成学习后主题进入该组。

### 6.2 保留现有推荐契约

- 全局语境仍选择现有逻辑允许的非空分组推荐，分组语境只取当前组；不增加推荐数量、评分、收藏或 dismissed 字段。
- 已在学习库出现的推荐不显示，避免与正式主题同时出现。
- 首次加载、刷新覆盖、5 秒防抖、手动刷新、错误重试、`StarOrbit` 和策略入参不变。
- 推荐加载或失败只占用自己的推荐槽，不阻塞同组主题行。
- 空学习库仍渲染含意外之径的默认分组，不因 `library.length === 0` 把推荐一起隐藏；没有历史主题时不伪造分组灵感。
- 搜索只过滤主题行，推荐继续显示在所属组；无匹配时显示清除搜索动作。搜索匹配不会复制推荐或改变其目标组。
- 分组折叠时推荐与主题一起收起；分组计数只统计正式主题，不把推荐计入数量。

## 7. 学习主题列表

### 7.1 主题行结构

默认行高以 56px 为基准，随学习字号适度增长。行内顺序为：

1. 3px 分组色条。
2. 展开／收起 chevron。
3. 标题与「N 次学习 · 最近时间」。
4. 最近一次学习已有的报告／对话／图表／寓言摘要。
5. 状态：进行中、待复习、已复习或暂无记录。
6. 「继续」「复习」「更多」操作。

标题区域打开主题工作区，默认定位最近一次学习报告。chevron 只展开当前主题，不触发导航。折叠态的已有产物摘要可点击，直接打开最近一次学习的对应页签；不存在的产物只弱化显示，不在折叠态隐式触发生成。

「继续」「复习」保持可见，不依赖 hover 才能发现。「更多」包含重命名和归档；重命名仍原位编辑，Enter 提交，Esc／blur 取消。归档沿用当前 IPC 和 Toast，成功后树与墙同时隐藏，设置中的恢复入口不变。

### 7.2 展开 session

展开区域按 sessionNumber 倒序展示，每行包含：

- 第 N 次学习、日期和归档状态。
- 报告、对话、图表、寓言、复习五类入口。
- 更多菜单中的「注销本次」，沿用现有附件清单和不可撤销确认。

点击已有产物打开 `StudyTopicBoard`，同时设置 `dirName`、`sessionNumber` 与目标 tab。无报告时图表／寓言保持现有不可用解释；有报告但无产物时显示「生成图表」「唤醒寓言」，沿用既有生成任务、寓言风格弹层、进度和失败重试，不自动调用模型。

归档中的 session 显示「整理中」，不禁用同主题其他 session。后台完成的新报告在主题行显示非纯文本的光点 + 「新报告」入口，点击打开现有 `ArchiveReportModal`；关闭只 dismiss 当前 `dirName`。

学习墙与第二列复用 `studyExpandedTopics`：同一主题在两侧同步展开，但展开状态不等于选中状态，也不持久化到磁盘。

### 7.3 拖拽

从主题行非按钮、非输入区域按下并移动超过 6px 后唤出 `GravityField`。保留：

- 分组卫星圆布局与分组色。
- 72px 吸附阈值。
- `moveTopicToGroup` 写回。
- Esc、无效目标和写回失败不改变映射。

点击与拖拽继续分离；session 行不发起主题拖拽。卫星场是辅助路径，第二列分组指南中保留图示说明。

## 8. 主题工作区与正式学习

`StudyTopicBoard` 保持当前结构：返回学习列表、继续学习、复习、更多、历史 session 选择，以及报告／对话／图表／寓言／复习页签。

从列表产物入口进入时选中对应 session 和 tab；从标题进入时选择最近 session 的报告。返回学习墙沿用 `openStudyWall`，不重新引入独立阅读弹窗。

正式学习仍常驻来源列与学习第二列，二者独立收起。切来源、打开其他主题和返回前继续执行 `withStudySaved`；恢复同一 live session 不重复 kickoff，后台 SSE 和摘要继续按 `abortId` 守卫。本设计不改变这些生命周期契约。

## 9. 学习字号与来源导航

### 9.1 字号作用域

复用 `studyFontSize` 的六档：`sm / base / lg / xl / 2xl / 3xl`，默认仍为 `lg`，现有跨重启持久化不变。

| 区域 | 是否随 `studyFontSize` 变化 |
|---|---|
| 四来源导航及底部入口 | 否 |
| 学习第二列标题、搜索、分组、主题、session | 是 |
| 学习墙页头、语录、推荐、主题行、session 行 | 是 |
| 主题工作区标题、页签、报告与对话正文 | 是 |
| 正式学习对话与外部资料摘要 | 是，沿用现有行为 |
| 确认框、准备弹层、记事板 | 否，沿用各自字号 |
| 写作、博客、书籍、设置 | 否 |

学习第二列以派生的 UI 字号缩放，正文报告沿用 `STUDY_FONT_STYLES`；元数据比标题小一级，不把整个页面简单设为同一像素值。放大后允许行高增加和文本换行，不截断核心操作。

### 9.2 来源导航对齐

- 每个图标使用固定 `20 × 20px` 居中槽，文本基线和行高一致。
- 所有导航项始终预留 3px 左边框；未选中为透明，选中只改颜色与背景。
- 学习 `✦` 使用与其他图标一致的实际字形容器，不用字符自然宽度参与布局。
- 展开与收起态均验证图标中心线；本次不改变来源列宽度、折叠逻辑或底部入口。

## 10. 浮层设计

`GuidePopover` 与 `DemoNotePopover` 使用同一浮层原则：

1. 通过 Portal 挂载到 `document.body`，不受来源列、第二列或主区的 `transform`、`overflow`、堆叠上下文影响。
2. 默认放在锚点下方 8px，宽 320px，最大高度 60vh；左右至少留 8px。
3. 下方空间不足时翻到锚点上方；内容过高只滚动浮层内部。
4. 浮层层级高于页面列与背景，低于需要独占交互的确认模态。
5. Esc、外部点击和窗口 resize 关闭；打开时不触发来源切换或主题导航。
6. 分组指南文案更新为「主题行」「分组内推荐」和新策略入口位置，原两张演示图继续保留。

实现时优先复用 `DemoNotePopover` 已采用的 Portal 方式，不另建通用浮层系统。

## 11. 文章／仓库列表与卡片

### 11.1 工具栏与视图状态

工具栏保留「文章专辑墙／仓库专辑墙」、篇数和排序，在最右增加两个图标按钮：

- `☷` 列表，aria-label「列表视图」。
- `▦` 卡片，aria-label「卡片视图」。

新增持久化 `writingWallViewMode: Record<WritingRoot, 'card' | 'list'>`，默认 `{ writing: 'card', repository: 'card' }`。文章与仓库互不影响，重启后恢复；笔记不读取该字段。

### 11.2 文件行

列表行以 68px 为基准，包含：

1. 48px 方形封面缩略图；使用现有生成封面，无封面时使用当前来源渐变／文件类型兜底。
2. 标题与相对路径。
3. Markdown 字数；非 Markdown 显示类型，不伪造字数。
4. 最近修改时间。
5. 当前文件支持的封面操作和删除入口。

点击行主体调用现有 `selectWritingFile`。封面生成仍是原位静默进度，完成后「待挑选」，不自动弹窗；删除继续使用现有永久删除确认，成功后刷新树与墙且不自动打开第一篇。

文章与仓库继续使用 `buildWritingWallGroups`：父子目录嵌套、子组默认收起、父组计数含后代、根文件归入未分组。默认顺序／最近修改／字数排序只影响组内文件，不改变磁盘顺序。

### 11.3 卡片兼容

切回卡片后恢复当前 3:4 `AlbumCard`、封面画幅、hover 字数、生成动画与删除位置。两种视图只是同一文件的展示适配，不复制 IPC、缓存或 frontmatter 逻辑。

## 12. 视觉规格与响应式

- 学习主题行不使用 3:4 比例、大阴影或独立封面画幅；使用细分隔线、轻微 hover 背景和分组色条。
- 推荐卡保持原标签、边框、标题与钩子样式，宽度占满当前分组内容区。
- session 展开区相对主题行缩进，使用左侧层级线，不做成另一组浮起卡片。
- 文件列表缩略图固定小画幅，不把卡片封面直接缩成难以辨认的整行背景。
- 深色与报纸模式沿用当前色板；不因移除学习墙版式按钮而删除报纸样式。

主区宽度不足时按顺序降级：

1. 学习行先隐藏折叠态产物摘要，保留标题、状态、继续、复习和更多。
2. 文件行先隐藏相对路径，再隐藏修改时间；标题、字数／类型和核心操作保留。
3. 更窄时允许主题标题两行、操作换行，主区不出现横向滚动。
4. 来源列和第二列继续独立收起；收起只改变宽度，不卸载学习会话或重置展开状态。

## 13. 组件与状态边界

### 13.1 学习

- `StudyWall`：组装页头、未完成会话和分组数据，不再使用 `AlbumGrid` 渲染学习主题。
- 新增学习域内 `StudyTopicList` / `StudyTopicRow`：承载主题与 session 展示；可以继续放在 `src/components/study/`，不进入共享 `album-wall/`。
- `StudyTopicCard` 在列表替换后若无调用方，作为本次改动产生的孤儿删除。
- `study-wall.ts`：增加纯函数，按组返回推荐与主题，集中处理意外之径目标组、去重和空库推荐。
- `StudySourcePanel`：只接字号变量与弹层 Portal，不改分组管理语义。
- `StudyTopicBoard`、`SessionFileContent`：接收相同学习正文尺寸，不改读取和生成 IPC。

### 13.2 写作

- `WritingWall`：按 root 读取视图模式，在现有卡片分支与文件列表分支间切换。
- 文件列表是写作域适配器，文章与仓库共用；不与学习主题行合并。
- `AlbumWall`、`AlbumGroupSection` 继续作为共享分组骨架；`AlbumGrid`、`AlbumCard` 保持现有卡片消费者不变。

### 13.3 状态与数据

## 14. 状态与错误处理

| 场景 | 预期 |
|---|---|
| 空学习库 | 保留推荐与新学习；可点击推荐进入对应组，不伪造主题行 |
| 空分组 | 有推荐则显示推荐和「从本组开始」；无推荐保留真实空态 |
| 推荐加载 | 原动画只在推荐槽内显示，主题列表可操作 |
| 推荐失败 | 原错误与重试留在推荐槽，不遮挡主题 |
| 搜索无结果 | 保留分组树、推荐、未完成会话和清除搜索 |
| 归档中 | 合并 pending session，只标记对应行；完成后清理并 rescan |
| 新报告完成 | 当前主题显示入口；打开／关闭不影响其他报告或新前台会话 |
| 图表／寓言失败 | 保留报告、对话和已有产物，可在原位重试 |
| 文件元数据失败 | 单个文件行回退，不清空目录或正文 |
| 封面生成失败 | 保留旧封面并 Toast；候选保存失败仍允许重试 |
| 删除失败 | 保留文件行／卡片和错误提示 |
| 字号极值 | 对应加减按钮禁用，布局不重叠 |
| 浮层靠近边缘 | 自动收敛或翻转，不被裁切，不遮挡为无法关闭 |

## 15. 功能保全清单

实现验收必须逐项确认：

- 新建、继续、复习准备流程与 `groupId` 正确。
- 推荐策略、刷新、缓存、错误重试与已入库去重不变。
- 新建、重命名、解散分组与「全部」筛选不变。
- 主题重命名、归档、设置恢复与拖拽换组不变。
- 历史 session、后台归档、新报告、删除 session 与附件确认不变。
- 报告、对话、图表、寓言、复习的打开、生成与失败恢复不变。
- 正式学习快照、后台 SSE、外部资料、单一 live session 与返回保存不变。
- 文章／仓库打开、dirty 保存后返回、分组排序、封面、字数和删除不变。
- 博客、笔记、书籍及共享卡片组件无非必要视觉或交互回归。
