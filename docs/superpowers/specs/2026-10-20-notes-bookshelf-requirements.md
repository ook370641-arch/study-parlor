# 笔记书架 — 需求与功能清单

> 来源：记事板待办「写作笔记分区（书架）」+ 2026-10-20 两轮脑暴。
> 本文档只定**需求与功能**，不定实现与 UI 细节（留待设计稿阶段）。

---

## 1. 背景与问题

阅读笔记当前散落在学习库各处，没有统一管理：

- **Anthropic 博客**：已读状态记在 `Anthropic博客/.collection.json` 的 `read` 列表，旁注记在文章旁的 `*.annotations.md`——读完即沉底，无法回顾"我读过什么、觉得怎么样"。
- **hermes 报告**：库外日报 HTML（file:// 链接），含已读文章线索，但不进库、不可评注。
- **写作区**：偶有随手记的文章笔记，混在 `writing/` 与 `repository/` 里，与正式写作、旧积累无区分。

结果：想回查"最近读的文章里哪篇值得再看"时没有入口。

## 2. 目标 / 非目标

**核心定位：笔记以正文为主体。** 元数据（评分/摘要/亮点）是索引与筛选手段，真正的价值承载在每条笔记的正文里——读完一篇文章后的想法、摘抄、延伸思考都写在这里。

**目标**

- 在写作分区下新增第三个分区「笔记」，作为所有阅读笔记的统一书架。
- 每条笔记 = 一篇可自由书写的正文 + 一组元数据字段（文章名、网页、时间、星标、一句话摘要、核心亮点）。
- 提供低摩擦的收录路径，让"读完一篇 → 上书"一步完成。
- 视觉上呈现书架质感；Anthropic 博客来源的文章有特定标识。
- 存量已读文章（A 社博客 read 列表）本期一次性导入。

**非目标（本期不做）**

- 标签体系、搜索、知识图谱。
- 多设备同步、导入外部工具（如 Obsidian 插件、Readwise）。
- 自动抓取网页全文（笔记只存元数据与链接，全文链接回原网页）。

## 3. 已确认决策（2026-10-20）

| 决策点 | 结论 |
|---|---|
| 位置 | 写作分区下第三分区「笔记」（与 新写作 / 过去积累 并列） |
| 存储 | 每条笔记一个 `.md`，置于 `<学习库>/notes/`，frontmatter 存元数据、body 即正文 |
| 网页字段 | 存原始 URL（http/https）；hermes 报告里的 file:// 链接原样保留 |
| 评分 | 星标（1–5 星，可不打星） |
| 存量导入 | 本期完成：把 `.collection.json` 的 `read` 列表批量生成笔记条目 |

## 4. 数据模型（需求级）

每条笔记一个 `.md` 文件：

| 字段 | 位置 | 说明 | 来源 |
|---|---|---|---|
| **正文** | md body | 笔记主体：想法、摘抄、思考，自由书写 | 手填（可空） |
| 文章名 | frontmatter | 标题 | 收录时自动带入，可改 |
| 网页 | frontmatter | 原文 URL（http/https 或 file://） | 收录时自动带入，可改 |
| 时间 | frontmatter | 收录/读完时间 | 自动 |
| 星标 | frontmatter | 1–5 星 | 手填 |
| 一句话摘要 | frontmatter | 一句话概括文章 | 手填 |
| 核心亮点 | frontmatter | 最值得记住的点 | 手填 |
| 来源标识 | frontmatter | `anthropic` / `hermes` / `manual` | 自动 |

## 5. 功能清单

按优先级分组；P0 为本期交付范围。

### P0 — 本期交付

- **F1 笔记分区**：写作分区下新增第三根「笔记」（与 新写作 / 过去积累 并列），左栏列表以书架卡片形式呈现条目。
- **F2 正文编辑**：点开笔记即可书写正文，编辑体验对齐写作区（Milkdown + autosave），这是本功能的重心。
- **F3 元数据编辑**：文章名/网页/星标/摘要/亮点可编辑；新建表单最少只需文章名+网页即可先占位。
- **F4 书架浏览**：卡片式书架视觉；卡片上可见文章名、星标、来源徽标；支持按时间/星标排序。
- **F5 来源徽标**：来源为 Anthropic 博客的条目带 A 社特定标识，一眼可辨。
- **F6 存量导入**：一次性把 `.collection.json` 的 `read` 列表批量生成笔记 `.md`（文章名/URL/时间/来源自动，星标/摘要/亮点留空待补）。

### P1 — 一键收录（下期）

- **F7 博客已读一键上书**：Anthropic 阅读器（或已读列表）加「存入书架」按钮，自动带文章名/URL/时间/来源，随后弹出补填星标/摘要/亮点。
- **F8 hermes 报告收录**：hermes 报告中的文章链接可一键上书（file:// 链接同样存网页字段）。

### P2 — 体验增强（可延后）

- **F9 AI 预填**：上书时调 LLM 预生成一句话摘要/核心亮点草稿，用户改后保存。
- **F10 与旁注联动**：书架上能看到该文章的旁注数量，点击跳回原文旁注。
- **F11 星标筛选/高分架**：按星标过滤，"值得重读"视图。

## 6. 交互模式（文字描述）

- **主视图 = 书架**：左栏以书脊/卡片陈列笔记条目，卡片上可见文章名、星标、来源徽标。
- **详情 = 正文编辑器**：点开卡片进入笔记，主区是正文编辑（autosave），元数据在头部/侧栏就地编辑。
- **收录 = 阅读处按钮**（P1）：在阅读场景原地完成，不打断阅读流；按钮反馈"已上书"。
- **新建 = 表单/快速条**：书架顶部一个入口，最少只需文章名+网页即可先占位，其余后补。
