# 学习来源、分组树与学习专辑墙重组设计（2026-11-17）

## 1. 背景与目标

记事板需求 `nmwkq1uy3cwnd` 要求把「点亮灯火」的学习能力完整迁入「夜航简报」。经过三轮评审，本次不再是旧 `Home` 的页面嵌入，也不把学习记录改成 session 级分组，而是围绕**主题**重建学习来源：

1. 「学习」成为夜航简报的新来源，位于来源导航原有顺序的最上方。
2. 学习来源沿用其他来源的三栏结构：来源列、可收起的第二列、内容工作区。
3. 第二列以「分组 → 主题 → 第 N 次学习」组织内容；主题展开后才显示 session。
4. 内容工作区提供类似专辑墙的学习墙，上方承载新主题推荐，下方承载主题卡。
5. 正式学习对话中，来源列和第二列仍然常驻挂载；两列均可收起，收起后保留各自窄栏。
6. 现有卫星引力场拖拽保留，继续承担主题换组的仪式与空间反馈。

本文是全功能设计与验收事实源。此前的 V1/V2 可视化稿包含已被否决的入口、层级、全局固定侧栏、session 级分组、分组主页与归档视图，不得作为实现依据。

## 2. 已确认决策

| 决策点 | 定稿 |
|---|---|
| 学习卡的基本单元 | 一张卡代表一个主题，不代表一次 session |
| 第二列层级 | 分组 → 主题；主题展开后为第 N 次学习 |
| 分组归属 | 保持主题级分组，不做数据迁移，不允许同主题不同 session 分属不同组 |
| 来源列 | 新增「学习」来源，但原有展开／收起逻辑完全保留 |
| 第二列 | 仿照其他来源，带收起按钮；收起后窄栏仍存在 |
| 学习中的第二列 | 常驻挂载，状态与学习前后共享；可以收起，不是强制展开 |
| 学习墙 | 顶部新主题推荐，下方主题专辑卡；分组用于筛选学习墙 |
| 卡片封面 | 分组色、轨道／卫星纹样与文字信息组成排版卡，不新增 AI 封面任务 |
| 主题主页 | 默认最近一次学习报告；其他产物通过页内页签与历史 session 切换 |
| 学习中切换 | 自动保存并转入后台，不强制归档；同一时间只有一个前台学习对话 |
| 封面 | 完全保留现有布局与文案；「点亮灯火」仅不可点击，不重定向、不删除 |
| 简报入口 | 「夜航简报」恢复上次退出时使用的来源；无历史时沿用现有默认来源「写作」 |
| 归档主题 | 不新增归档视图，不在学习墙或第二列展示，不提供「全部／待复习」筛选 |
| 设置 | 不单独设计，不改变设置中心信息架构 |

「待复习」可以继续作为主题卡或 session 的状态信息，但不构成视图、页签或筛选条件。

## 3. 范围与非目标

### 3.1 本次范围

- 学习来源的导航、第二列、学习墙、主题主页和正式学习承载。
- 新建、继续、复习三种学习准备流程。
- 分组新建、重命名、解散、筛选和卫星引力场拖拽换组。
- 报告、对话、图表、寓言、复习记录的统一阅读。
- 推荐、生成、归档、异常、空态、响应式与两种主题的必要状态。
- 旧 `Home` 内容的迁移与旧路由退役。

### 3.2 非目标

- 不改写作、博客、书籍的来源行为与第二列交互。
- 不改设置中心，不单独产设置页设计稿。
- 不新增归档主题视图、归档卡、恢复入口或「全部／待复习」筛选。
- 不把分组归属改成 session 级，不迁移学习库目录结构。
- 不为学习卡引入 AI 图片封面，不改变学习、复习、推荐和归档的文件格式。
- 不移除封面「点亮灯火」按钮，不让它自动跳转夜航简报。
- 不实现多前台对话并行，不改变后台 SSE、搜索和摘要的单会话契约。

## 4. 信息架构

### 4.1 页面模型

应用保留封面、夜航简报、正式学习、设置四类顶层场景：

```text
封面（现状不变）
├─ 点亮灯火：可见但不可点击
└─ 夜航简报：进入持久化的上次来源

夜航简报
├─ 学习（新增，首位）
│  ├─ 学习墙
│  └─ 主题主页
├─ 写作
├─ 博客
└─ 书籍

正式学习
├─ 固定挂载的来源列
├─ 固定挂载的学习第二列
└─ 当前前台会话

设置
└─ 保持现状，不属于本次视觉重组
```

旧 `home` 页面不再作为可导航目的地。新学习来源稳定后，删除旧路由渲染与无意义的 `goto('home')`；封面按钮保持可见但禁用，因此不会因为旧路由移除而出现跳转目标缺失。

封面「点亮灯火」保留原 class、尺寸、位置和文案，使用 `aria-disabled="true"` 并忽略鼠标与键盘激活，避免原生 `disabled` 样式改变封面。它不重定向、不新增提示，也不承担迁移入口。

### 4.2 上次来源恢复

沿用现有持久化 `briefingSource`，不另建重复的 `lastBriefingSource`：

- 每次真实来源切换时保存。
- 从封面进入夜航简报时直接读取该值。
- 开始学习时确保当前来源为「学习」，因此退出应用后再次进入可恢复学习来源。
- 设置页来源返回继续使用 `settingsReturnTo`，不把「设置」写成简报来源。
- 旧状态没有合法来源时回退「写作」，与当前默认值一致。

### 4.3 三栏职责

学习来源与学习中都使用同一套三栏骨架：

| 栏 | 学习墙／主题主页 | 正式学习 |
|---|---|---|
| 第一列：来源 | 学习、写作、博客、书籍；现有展开／收起不变 | 同一来源列保持挂载，可切换来源 |
| 第二列：学习树 | 新学习、分组、主题、session、进行中 | 同一棵树保持挂载，可选择其他主题 |
| 第三列：工作区 | 学习墙或主题主页 | 当前学习对话与其临时面板 |

学习第二列的展开状态跨学习墙、主题主页和正式学习保持。来源列沿用现有本地折叠交互，不新增持久化规则；正式学习复用同一组件，不发明另一套折叠行为。

## 5. 来源列与第二列

### 5.1 来源列

`BriefingSourceSidebar` 只增加学习导航项，不重构现有折叠机制：

- 学习位于写作之前，图标沿用克制的发光／轨道符号，不引入新装饰语言。
- 展开时显示图标与「学习」；收起时显示图标与当前态，窄栏不消失。
- 现有来源切换、写作对照挑选器拦截、HTML 删除模式 flush、设置与返回封面逻辑保持。
- 正式学习复用同一组件，不实现第二个学习专用来源栏。

### 5.2 学习第二列结构

第二列基于 `BriefingListColumn`，标题为「学习」，带与其他来源一致的收起按钮：

```text
学习                                      ◀
[+ 新学习]
[搜索主题……]

● 进行中
  为什么好的解释难以替代？                 继续

▾ 认知科学                              4
   知识的诅咒                         2 次
   ├─ 第 2 次 · 11-16 · 待复习
   └─ 第 1 次 · 11-09 · 已复习
   记忆的重构                         1 次
▸ 设计与表达                            3
▸ 技术与社会                            5
▾ 未分组                                6

+ 新建分组
```

以上仅表达信息层级，不要求把主题次数和 session 全部挤在同一行；实际绘制沿用第二列现有行高、缩进、字号与滚动规则。

### 5.3 选择与展开行为

- 分组 chevron 只控制展开，分组名称用于筛选学习墙；两种操作不互相意外触发。
- 点击分组筛选墙时保留该组展开状态，其他组状态不被重置。
- 主题 chevron 控制 session 展开；点击主题名称打开主题主页并默认最近一次报告。
- 点击具体 session 打开该次学习的对应内容，默认报告页签。
- 展开主题、选中主题和选中 session 是三个独立状态，切来源后返回可恢复。
- 搜索只过滤主题与分组展示，不改变分组归属；清空搜索恢复原有展开状态。
- 不提供「全部／待复习／已归档」这组学习状态或归档筛选器；分组语境仍保留现有「全部」分组入口，用于清除分组筛选并显示全部分组段落。

### 5.4 收起与空态

- 第二列收起后只保留窄栏与展开按钮，内容按 `BriefingListColumn` 现有约定卸载。
- 正式学习中收起第二列只释放内容宽度，不销毁学习树的选择与展开状态。
- 空库、空分组、搜索无结果时，两列与新学习入口始终存在。
- 空分组显示「从本组开始学习」；不伪造推荐或学习记录。

## 6. 学习专辑墙

### 6.1 页面结构

学习墙复用 `AlbumWall`、`AlbumGrid`、`AlbumCard` 与 `AlbumGroupSection` 的布局能力，顺序固定为：

1. 页面标题与既有阅读控制。
2. 新主题推荐区。
3. 当前分组语境下的主题专辑墙。

点击左侧分组只筛选这面墙，不再增加与墙重复的「分组主页」。未选择分组时展示所有未归档主题，按分组组织墙内段落；选择分组后只展示该组。

### 6.2 新主题推荐

- 推荐区展示 1–3 张推荐卡，沿用现有随机灵感、分组灵感与续谈推荐能力。
- 当前分组语境明确时优先展示该组灵感；无分组语境时展示跨组推荐。
- 推荐卡与正式主题卡视觉同族但更有引导性，包含主题、钩子与来源说明。
- 点击推荐卡打开新学习准备弹层，并带入主题和当前分组。
- 推荐被学习并归档后转为正式主题卡，并从当前推荐位移除，不与自己的主题卡同时出现；后续推荐批次仍沿用现有生成逻辑，不新增持久 dismissed 数据。
- 刷新与策略切换沿用现有逻辑，不额外发明推荐评分、收藏或 dismissed 数据。
- 推荐区最多展示 3 张卡：全局语境为 1 张随机灵感与按分组顺序最多 2 张非空分组灵感；分组语境为当前组灵感与 1 张随机灵感。未进入当前推荐位的分组卡仍可经该组筛选访问，不得因此跳过分组或丢失缓存。续谈方向推荐继续保留在继续学习的 `PreStudyModal`，不另造一类主题卡。

### 6.3 主题卡

一张卡代表一个 `TopicMeta`：

- 标题：`topic.title`。
- 分组：颜色与名称来自 `groupId`。
- 次数：`sessionCount`。
- 最近学习：`last_studied`。
- 状态：进行中、待复习、已复习等仅作信息标记，不形成筛选视图。
- 封面：分组色、轨道／卫星纹样与排版，不调用 AI 生成图片。

默认点击卡进入主题主页。悬停只提供「继续」「复习」「更多」等少量快捷操作；报告、对话、图表、寓言、复习记录不再全部挤在卡片上。

### 6.4 学习墙状态

- 默认墙：推荐区与主题卡均可见。
- 分组墙：仅当前组推荐与该组主题卡。
- 空库：保留推荐和新学习，展示真实空态文案。
- 空分组：保留新学习与从本组开始，不显示其他组卡片。
- 推荐加载：使用骨架或既有等待语言，不遮挡主题卡。
- 推荐失败／无推荐：只影响推荐区，主题墙仍可完整使用。
- 搜索无结果：保留分组树、推荐入口和清除搜索动作。

## 7. 分组管理与卫星引力场

### 7.1 分组操作

沿用现有 `groups`、`groupMapping` 与分组 IPC：

- 新建分组后立即出现在第二列，可展开并可从本组开始学习。
- 重命名只更新分组名称，卡片与第二列同步刷新。
- 解散分组只把组内主题移回默认／未分组，不删除主题文件。
- 归档主题与删除 session 是独立既有语义；本次不新增归档展示或恢复界面。

### 7.2 保留卫星拖拽

现有 `GravityField` 是本次必须保留的核心交互，不用普通树拖拽或虚线放置框替代：

1. 从学习墙的主题卡开始拖拽。
2. 唤出卫星引力场，分组作为卫星，拖拽主题跟随指针。
3. 靠近分组时沿用现有距离与吸附反馈，明确将落入哪个组。
4. 松手调用 `moveTopicToGroup`，成功后同步第二列与墙。
5. 远离有效目标、Esc 或取消时不改变归属。
6. 写回失败时保留原分组并提示，不出现视觉已移动但数据未移动。

第二列只呈现清晰的树状结果，不新增另一套树内拖拽逻辑。窗口 resize、快速取消、拖拽中切来源、分组增删和空组吸附必须在实现前列出边界并覆盖测试。

## 8. 主题主页与学习产物

### 8.1 默认视图

点击第二列主题或学习墙主题卡后进入主题主页：

- 标题、分组、学习次数和最近学习时间。
- 主操作：继续学习、开始复习；其他管理动作收进「更多」。
- 默认选中最近一次 session 的报告。
- 第二列主题展开后可直接选择历史 session；主题内也提供简洁的 session 时间线。

继续学习沿用 progress 模式，复习沿用 review 模式；二者都保留准备弹层，不直接绕过用户确认。

### 8.2 页签

| 页签 | 数据来源 | 空态／能力 |
|---|---|---|
| 学习报告 | 当前 session 的报告 Markdown | 无报告时解释归档状态 |
| 谈话记录 | 当前 session 的对话记录 | 保留既有 Markdown 渲染 |
| 图表 | 当前 session 的 SVG／图像 | 支持生成中、查看、失败重试 |
| 寓言 | 当前 session 的寓言文件 | 支持风格选择、生成、查看、重新生成 |
| 复习记录 | 当前 session 的复习文件 | 无记录时提供复习入口 |

学习产物在第三列页内展示，替代学习来源中的全屏 `SessionViewer` 弹窗。读取中与读取失败也留在页内，来源列和第二列始终可用。

### 8.3 归档报告

主动结束学习后，归档报告仍使用既有 `ArchiveReportModal`，因为这是需要用户确认结果的模态任务，不属于普通文件浏览。归档中的后台完成报告可从主题主页再次查看，但不新增归档主题列表。

## 9. 正式学习

### 9.1 双列常驻

正式学习页面保留会话主体，同时挂载来源列和学习第二列：

- 两列均可独立收起，窄栏始终存在。
- 展开／收起状态与学习墙、主题主页共享。
- 会话正文使用剩余宽度，不通过卸载第二列换取空间。
- 小窗口不自动改变用户的折叠选择；第二列自身滚动，正文保持最小可读宽度，空间不足时允许页面横向滚动。

### 9.2 切换与后台会话

当前会话存在时，点击其他主题、session 或来源：

1. 保存当前会话快照。
2. 当前 SSE、搜索、摘要等后台工作继续，不强制归档。
3. 打开目标内容；同一时间只有一个前台学习对话。
4. 第二列「进行中」提供恢复入口，恢复后看到完整后台结果。

目标切换失败时保持当前会话可用。不得因为打开报告、浏览其他来源或收起第二列而销毁会话。

开始或恢复另一段会话属于替换当前 live session，不属于普通浏览：无论当前停留在正式学习还是简报，都先保存旧会话最新快照，再按单 live session 契约中止被替换的旧流；不能让离开页面后新收到的内容丢失。

### 9.3 会话状态

正式学习必须保留并适配新骨架的状态包括：

- 首次等待响应、流式回复、用户发送中断、流式错误。
- 本地资料卡、外部资料开关与外部资料摘要工作区页签。
- 学习字号、主题、换画等现有控制。
- 退出动画、归档中、归档报告、归档失败与恢复暂存。

外部资料摘要在第三列工作区以「对话／外部资料」页签展示，不再用覆盖右侧内容的固定摘要面板。资产卡和卡片内展开仍保留；打开摘要页签不重新请求资料，切走主题或来源不取消后台搜索与摘要。

## 10. 学习准备与生成流程

### 10.1 三种准备弹层

- 新学习：可输入新主题、选择分组、难度、随机性与资料。
- 继续主题：带入既有主题与分组，展示续谈方向建议。
- 复习：带入主题与 session，沿用复习模式和既有复习记录追加逻辑。

从分组或分组推荐发起时默认该组；从全局推荐发起时使用当前分组语境，没有语境时进入默认组。取消后回到原来的墙或主题主页，不改变来源。

### 10.2 图表与寓言

- 图表生成在主题主页对应页签内反馈生成中、成功与失败。
- 寓言先经过既有风格选择；生成后可查看与重新生成。
- 生成期间切换主题或来源不取消后台任务，回来时按真实状态呈现。
- 失败不伪造产物，不清除旧成功版本。

### 10.3 删除与复习反馈

- 删除 session 与解散分组分别使用明确文案的确认弹层。旧版没有独立「删除主题」入口，本次不新增主题文件删除能力；主题的既有管理动作是归档隐藏与设置恢复。
- 解散分组不写成删除学习文件；删除 session 不误写成删除整个主题。
- 复习完成保留 `ReviewFlash` 的既有反馈语言，完成后更新卡片状态但不新增待复习筛选。

## 12. 组件与状态边界

### 12.1 组件职责

建议围绕以下边界组织实现，名称可在计划中微调，但职责不得再次合并成巨型页面：

| 单元 | 职责 | 复用／依赖 |
|---|---|---|
| `StudySourcePanel` | 学习来源三栏编排与墙／主题切换 | `BriefingListColumn`、store |
| `StudyListColumn` | 分组树、主题树、session、搜索、进行中 | groups、library、unsavedSessions |
| `StudyWall` | 推荐区与主题专辑墙 | AlbumWall 系列、推荐 store |
| `StudyTopicBoard` | 主题主页、页签、session 选择 | 现有 Markdown／SVG 渲染 |
| `Study` | 前台会话与双列骨架 | 现有 session runtime、StudySourcePanel 树 |
| `study-wall` 纯逻辑 | 从 groups/library 派生墙与树视图模型 | 不直接 IPC、不直接操作 DOM |

`Home`、`StudyLibrary` 的职责迁入上述边界后再退役，不允许新旧两套学习首页长期并行。`GravityField` 与分组 IPC 保持复用，不重写一套视觉相似但行为不同的拖拽。

### 12.2 运行时状态

需要明确区分：

- 来源与两列折叠状态。
- 当前分组筛选、当前主题、当前 session、当前页签。
- 各分组与各主题独立展开状态。
- 学习墙与主题主页的显示关系。
- 进行中会话与后台生成状态。

分组展开、主题展开和当前选择不得共用一个布尔值。卡片与第二列从同一份 `groups + library + pendingArchives + unsavedSessions` 派生，避免两套计数和状态。

### 12.3 数据与 IPC

- `BriefingSourceId` 新增学习来源，旧值继续有效。
- `TopicMeta`、`SessionMeta`、`Group`、`GroupMapping` 不变。
- 主题换组仍调用 `moveTopicToGroup`，不引入 session 映射。
- 文件扫描、读取、复习追加、归档与生成 IPC 尽量复用；只有现有契约无法支持页内状态时才在计划中单独论证新增通道。
- 学习墙视图模型不修改用户 Markdown，不为排版卡写伴生封面文件。

## 13. 错误与竞争处理

- 全局来源列、第二列、背景与换画控制不受单个文件加载、推荐失败或空态影响。
- 写作 HTML 删除模式 flush 失败时继续中止来源切换，不强行进入学习。
- 分组写回失败时回滚视觉预选并保留原映射。
- 切换主题或来源前先保存会话；保存失败应提示并允许留在当前会话，不静默丢失。
- 后台完成结果按 session 标识归位，不弹旧报告打断新的前台会话。
- 推荐、图表、寓言与外部资料任务均按真实异步状态展示，不设置伪造进度。
- 快速展开／收起、连续切换、resize 与拖拽取消不得卸载全局 Chrome 或丢失选择。

## 14. 测试与验收

### 14.1 单元测试

优先覆盖纯逻辑：

- 分组树与学习墙使用同一主题视图模型，计数一致。
- 主题卡聚合 `sessionCount`、最近学习与复习状态。
- 分组筛选不包含归档主题，不生成学习状态或归档筛选配置；「全部」只用于清除分组筛选。
- 分组和主题展开状态互不影响。
- 推荐归档后转正式主题卡，当前推荐位不再与该主题卡重复。
- 来源缺省回退写作，合法旧来源不受学习新增值影响。
- 卫星拖拽取消、无效目标和写回失败不改变 `groupMapping`。

### 14.2 定向 E2E

必须覆盖以下关键链路，不跑全量 E2E：

1. 封面点亮灯火不可点击，夜航简报恢复上次来源。
2. 两列展开／收起无回归；学习第二列跨主题主页和正式学习保持，来源列不新增持久化。
3. 分组筛选、搜索、空库、空分组和无结果。
4. 推荐加载／失败／点击发起／归档后转卡。
5. 主题卡进入最近报告，历史 session 与各产物页签切换。
6. 学习墙拖拽唤出 GravityField，吸附、取消与换组成功。
7. 新建、重命名、解散分组、主题归档／设置恢复与删除 session 的确认语义。
8. 新学习、继续、复习准备流程与资料面板。
9. 正式学习等待、流式、中断、错误与后台恢复。
10. 学习中切换主题／来源，快照与后台任务不丢失。
11. 图表、寓言、归档、读取失败与恢复暂存。
12. 报纸模式、小窗口、全局记事板与 Toast 层级。

新增 spec 或组件时必须同步更新 `e2e/source-map.json`。按变更运行定向单元测试与 `e2e-changed.js`，不以全量测试作为默认门禁。

### 14.3 完成标准

- 第 11 章所有功能状态均有设计或明确复用现有组件的依据。
- 学习来源、主题主页和正式学习共享同一棵树与同一份数据。
- 旧 `Home` 不再可导航，封面仍保持原样且点亮灯火不可点击。

- 上条「全部／待复习筛选」仅指学习状态与归档筛选；用于清除分组筛选的「全部」分组入口必须保留。
- 卫星引力场拖拽与现有后台会话能力无回归。
- `npm run docs:check` 错误清零，相关定向测试通过。

### 16.6 外部资料工作区页签定稿

`ExternalMaterialsCard` 继续是正式学习正文顶部的资料资产区，不能因摘要页签新增而删除。其两种展开方式分工如下：

1. 点击资产卡标题行仍在卡片内展开／收起，继续显示收集中、失败、无结果、摘要和来源。
2. 点击「摘要 →」把工作区切到「外部资料」页签，展示完整 `ExternalSummaryContent`；不再渲染固定右侧 `ExternalSummaryPanel`，也不产生第二次搜索或摘要请求。
3. 工作区页签为「对话／外部资料」，仅在当前 session 存在外部资料资产时出现外部资料页签。切回对话不销毁资产卡、后台搜索或聊天流。
4. 页签正文复用 `ExternalSummaryContent`，因此 `[1]` 等来源编号锚点、来源列表、HTTP(S) 外链、Markdown 表格／代码样式不变。
5. 原摘要面板的「这些外部资料是怎么找来的」`DemoInfoButton` 与 `DemoNotePopover` 移到页签工具栏；说明弹层打开时 Esc 只关闭说明，否则外部资料页签下 Esc 先回对话，再一次 Esc 才执行保存并返回。
6. 页签不是模态框，不沿用点击外部关闭与 `aria-modal`；它使用 `role="tablist"`、`role="tab"`、`aria-selected` 和可聚焦页签按钮。
7. 学习字号继续作用于摘要；深色与报纸模式都保留可读性。切来源后再恢复同一 live session，页签与资料仍按运行时状态恢复；开始新 session 时重置到对话并清空旧资料。
8. 复习流程的 `files:readExternalMaterials` 和归档的 `files:writeExternalMaterials` 契约不变。本次不给 `SessionMeta` 增加外部资料字段，也不另造历史外部资料浏览器。

### 16.7 明确不做与审计发现的纠偏

- 不新增设置页视觉稿、归档主题列表、学习状态「全部／待复习」筛选、session 级分组、多 live SSE、AI 学习卡封面或独立删除主题 IPC。
- 「全部」分组入口不是归档筛选，必须保留；它清除 `activeGroupId` 后显示所有未归档分组段落。
- 旧寓言生成中按钮只是隐藏本地等待标记，并没有取消 IPC；新版展示真实任务状态，不把这个伪取消包装成实际取消能力。
- 旧分页是可替代的导航方式，不是数据能力；替代验收必须证明第 10 条及之后的主题仍可见、可搜索、可打开。
- `home` 画作仍被设置页和学习墙控制复用，删除旧 `Home` 组件不等于删除 `currentPaintings.home` 或相关设置。

### 16.8 功能保全交付门禁

- 每个实现任务在计划中引用本章相关行，并给旧选择器保留或测试迁移一个明确结果。
- 删除 `Home.tsx`、`StudyLibrary.tsx`、`SessionViewer.tsx` 或 `ExternalSummaryPanel.tsx` 前，用全局引用搜索证明新入口已覆盖本章能力；不能只靠页面截图判断。
- `home.spec.ts` 与 `library-pagination.spec.ts` 必须迁移为学习来源与全量主题可达性测试；其他既有 spec 只更新导航与页内选择器，不删除原断言来换取通过。
- 最终按本章逐行核对单元测试或定向 E2E 证据；无法自动化的视觉层级用报纸／深色与小窗口截图检查记录，不以「未运行」冒充通过。
