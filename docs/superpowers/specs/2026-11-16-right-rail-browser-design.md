# 阅读右栏内置浏览器设计

日期：2026-11-16

## 1. 背景与目标

文章和书籍阅读页的右栏已有「导读 / 对照」。本次增加第三个「浏览器」页签，让用户无需离开 Study Parlor 即可查阅网页，同时保持首版简单、可控。

已确认的交互方案为 **A · 紧凑单排**：保留单排常用工具，兼顾网页空间和操作可见性。技术路线采用 Electron `WebContentsView`，不使用 `<webview>` 或 iframe。

目标：

1. 网页可在右栏正常显示、滚动、点击链接和填写表单。
2. 地址栏同时支持 URL 与 Bing 关键词搜索。
3. 支持后退、前进、刷新、网页内查找和外部打开。
4. 页面在应用内各状态间保持，并在应用重启后恢复最后 URL 与登录状态。
5. 沿用主进程 → Preload → React 的隔离通信，不扩大网页权限。

## 2. 首版范围

### 2.1 包含

- 单页面浏览器，无多标签。
- 后退、前进、刷新、地址栏、网页内查找、系统浏览器打开。
- 地址栏关键词搜索；未写协议的网址自动补 `https://`。
- 当前网页内文字高亮、匹配计数、上一个 / 下一个。
- 网站 Cookie 与登录状态持久化。
- 最后成功访问的 URL 持久化。

### 2.2 不包含

- 多标签、书签、历史记录页面和下载管理。
- Chrome 扩展安装或兼容层。
- AI 读取、点击或控制网页。
- 网页转笔记、网页与导读 / 对照的自动联动。
- 自定义搜索引擎设置；首版固定使用 Bing。
- 跨重启恢复完整导航历史、滚动位置或未提交表单。

## 3. 交互设计

### 3.1 页签与工具栏

`ArticleGuideTabs` 增加「浏览器」，顺序为「导读 / 对照 / 浏览器」。文章和书籍均可进入浏览器，沿用现有右栏宽度、折叠和主题。

浏览器工具栏采用紧凑单排：

1. 后退、前进、刷新。
2. 可编辑地址栏。
3. 网页内查找。
4. 外部打开。

地址栏在导航成功后同步当前 URL，用户开始编辑时不被后续状态事件打断。后退、前进根据 `canGoBack()` / `canGoForward()` 禁用。

### 3.2 URL 与关键词搜索

地址栏提交时按以下规则处理：

- `http://` 或 `https://` 开头的合法 URL：直接访问。
- 不含空格的普通主机名：补 `https://` 后访问；localhost 与回环地址补 `http://`。
- 其余输入：作为关键词编码后访问 `https://www.bing.com/search?q=...`。
- `file:`、`javascript:`、`data:` 等协议不作为网址接受；这类输入不会被当作可执行导航。

URL 解析与搜索 URL 生成放在纯函数中，便于单元测试。

### 3.3 网页内查找

点击查找按钮展开查找条。浏览器可见时也响应 `Ctrl+F`；焦点位于网页内部时，由主进程 `before-input-event` 转发快捷键。

查找条包含关键词、匹配数量、上一个、下一个和关闭：

- 输入后由主进程在当前主框架遍历 DOM 文本节点，用网页选区高亮并滚动到匹配项。
- Enter 查找下一个，Shift+Enter 查找上一个。
- 查找结果直接返回当前匹配序号与总数；Electron 30 / 31 的最小复现中 `found-in-page` 不触发，因此不依赖该事件。
- 关闭查找条时清除网页选区。
- 新导航开始后清除旧匹配状态。

### 3.4 链接与外部打开

普通链接在当前页面导航。`target=_blank` 等新窗口请求不创建标签或新窗口，对合法的 HTTP(S) 地址改为当前页面打开。

「外部打开」通过 `shell.openExternal` 打开当前 URL；没有成功导航过时可使用地址栏中已确认的合法目标。外部打开前再次校验协议。

## 4. 状态与持久化

### 4.1 单个活动页面

每个应用主窗口至多持有一个浏览器 `WebContentsView`。文章和书籍共用这一实例，不随来源切换销毁。

以下操作只隐藏视图，不清空页面：

- 切回导读或对照。
- 切换文章 / 书籍来源。
- 折叠右栏。
- 离开阅读页。

因此应用内切换后仍保留页面滚动、表单内容和导航历史。主窗口关闭或销毁时才释放浏览器视图。

### 4.2 跨重启恢复

`StateJson` 新增 `browserLastUrl?: string | null`。主进程在成功导航后保存最后 URL，包括站内导航和 SPA URL 变化；不保存完整历史。

浏览器 session 使用固定的持久化 partition，Cookie、缓存和网站登录状态由 Electron 保存。

应用启动时不创建浏览器视图、不加载最后 URL。即使用户上次停留在浏览器页签，启动水合时也将该模式回退为「导读」；用户再次点击「浏览器」后才恢复 `browserLastUrl`。没有最后 URL 时显示地址栏空态，不自动打开默认网页。

## 5. 技术结构

### 5.1 主进程

新增独立的浏览器视图管理模块，职责仅限：

- 为指定主窗口懒创建、显示、隐藏和销毁 `WebContentsView`。
- 设置视图 bounds，执行导航与查找。
- 维护工具栏所需的 URL、加载、前进 / 后退状态。
- 将成功导航与查找结果通知渲染进程。
- 持久化最后 URL。

新增浏览器 IPC 域并注册到现有 `registerAllIpc`。Preload 只暴露类型化、固定用途的方法，不向 React 暴露原始 `WebContents` 或任意执行能力。

### 5.2 React

新增 `BrowserPanel`，包含工具栏、查找条、网页占位区域和加载 / 错误状态。`ArticleGuideTabs` 只负责页签与面板切换，不直接管理 Electron 视图。

网页占位区域通过 `getBoundingClientRect()` 提供位置，使用 `ResizeObserver` 和窗口 resize 同步 bounds。显示视图前先同步一次 bounds；组件卸载或面板隐藏时立即隐藏视图，避免原生视图覆盖其他 React 内容。

### 5.3 状态流

- React → 主进程：显示 / 隐藏、bounds、导航、前进 / 后退 / 刷新、查找、停止查找、外部打开。
- 主进程 → React：URL、标题、加载状态、可前进 / 后退状态、查找结果、加载错误、查找快捷键请求。

浏览器实例的所有权在主进程；最后 URL 由主进程持久化，Zustand 只保存水合后的恢复副本与当前面板模式，不保存 `WebContentsView` 对象。

## 6. 安全边界

浏览器视图使用独立 `persist:` partition，webPreferences 至少保持：

- `sandbox: true`
- `contextIsolation: true`
- `nodeIntegration: false`
- 不加载应用 Preload

该 session 拒绝摄像头、麦克风、定位、通知、剪贴板等权限请求，不设置证书错误绕过。主进程在地址栏导航、站内跳转、新窗口请求和外部打开处统一限制为 HTTP(S)。

网页与主窗口使用不同 session，不能读取学习库、应用状态或 Node 能力。外部打开只接受已校验 URL。

## 7. 异常处理

- 主框架加载失败时，在网页占位区显示加载失败、重试和外部打开；忽略用户取消导航等正常中断。
- 子资源或 iframe 失败不覆盖整个页面错误状态。
- 查找无匹配时显示 `0 / 0`，不弹错误。
- 视图尚未创建、主窗口已关闭或 WebContents 已销毁时，IPC 安全返回，不向已销毁对象发消息。
- 最后 URL 恢复失败时保留地址栏内容，允许修改后重试。

## 8. 文件与测试范围

预计新增：

- `electron/lib/browser-view.ts`：视图生命周期、导航、安全和持久化。
- `electron/ipc/browser.ts`：浏览器 IPC。
- `src/components/article-assistant/BrowserPanel.tsx`：工具栏、查找条和占位区。
- URL 解析单元测试与 `e2e/specs/right-rail-browser.spec.ts`。

预计修改：

- `electron/main.ts` / `electron/ipc/index.ts`：注册与窗口生命周期接入。
- `electron/preload.ts`、`src/types/index.ts`：类型化 API 与状态字段。
- `src/components/article-assistant/ArticleGuideTabs.tsx`、`src/store/index.ts`：第三页签与模式处理。
- `e2e/source-map.json`：定向测试映射。
- `docs/README.md`：功能域指针。

验证顺序：

1. URL / 搜索解析及持久化相关的定向单元测试。
2. 本地测试网页的定向 E2E：导航、搜索输入、滚动、页内查找、页签切换、折叠和来源切换后的状态保持；不依赖公网。
3. `npm run build`。
4. `npm run docs:check`。

E2E 会启动第二个应用实例，实施时必须遵循项目隔离规则并在运行前取得用户明确确认；不运行全量 E2E。

## 9. 验收标准

1. 文章和书籍右栏均出现「浏览器」，A 方案工具栏可用。
2. 输入 URL、主机名和关键词分别得到正确导航；非法协议不能执行。
3. 网页可滚动、点击和输入，后退 / 前进 / 刷新 / 外部打开正常。
4. 页内查找支持计数、前后匹配、快捷键和清除高亮。
5. 切换页签、来源、折叠右栏后页面状态仍在。
6. 重启后不在后台联网；再次进入浏览器可恢复最后 URL 和登录状态。
7. 网页无 Node、学习库、应用状态或系统权限访问能力。
8. 定向测试、构建和文档检查通过。
