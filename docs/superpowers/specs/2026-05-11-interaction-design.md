# 学者夜话 · 全套交互设计规范

> 日期：2026-05-11
> 设计理念：迈克尔·波兰尼「默会知识」× 极乐迪斯科风格
> 视觉语言：星辰宇宙 —— 知识如星光，在黑暗中逐渐成形

---

## 一、设计哲学

### 1.1 核心隐喻：星辰宇宙

波兰尼认为「我们知道的比我们说出的更多」——知识不是被"找到"的，而是在暗处被"照亮"的。

整个应用的交互视觉语言建立在**「星辰宇宙」**隐喻之上：

- **星点** = 知识的火花、灵感的闪烁
- **黑暗** = 未知的领域、等待探索的空间
- **光的聚散** = 学习的过程——从混沌到清晰
- **归巢/重燃** = 复习与回顾——星光不曾熄灭

### 1.2 统一视觉符号系统

| 符号 | 含义 | 出现场景 |
|------|------|---------|
| 旋转星点（3-4颗） | 思考中、运算中 | C1 思考指示器、C2 灵感加载、C3 文件加载 |
| 星点飞散/迸射 | 发出、提交、确认 | B5 发送反馈、B2 按钮按压 |
| 星点汇聚/凝聚 | 成形、出现、完成 | B4 消息入场、A4/D4 模态框展开、F2 复习确认 |
| 星点归巢 | 结束、返回 | A3 Study→Home |
| 涟漪/水波 | 过渡、进入 | A2 Home→Study（静水深流） |
| 卷轴/书页 | 成果的展示 | F1 学习报告 |
| 呼吸光晕 | 等待、生命感 | B3 Input 聚焦 |

### 1.3 动画节奏规范

| 类型 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 微反馈 | 150-200ms | ease-out | 按钮按压、发送反馈 |
| 快速过渡 | 250-400ms | ease-in-out | 模态框开关、折叠面板 |
| 标准过渡 | 500-700ms | ease-out | 页面切换、报告展示 |
| 慢速呼吸 | 2000-3000ms | ease-in-out | 思考指示器、加载状态 |

## 二、交互设计详表

### 极高频 · 每轮会话 20-50 次

#### C1 · 「正在思考…」AI 思考指示器

- **拍板方案**：方案四「星点旋绕」
- **当前问题**：仅脉冲点 + 文字，缺乏辨识度
- **新设计**：
  - 3 颗星点（ember + parchment 色）围绕中心缓慢旋转
  - 周期：2s linear infinite
  - 文案保持「正在思考…」
  - 位置：AI 回复区域下方，与输入框之间
- **实现**：纯 CSS，3 个 div 用不同 transform-origin 做 orbit 动画
- **代码量**：~20 行 CSS

#### B4 · ChatBubble 消息入场动效

- **拍板方案**：方案四「星尘凝聚」
- **当前问题**：消息直接出现，无过渡
- **新设计**：
  - 消息气泡出现时，角落有 2-3 颗星点一闪而过（200ms）
  - 星点颜色与消息类型对应：AI 消息 = ember 色，用户消息 = parchment 色
  - 基础过渡：opacity 0→1 + 轻微 translateY（4px→0）
- **实现**：消息渲染时添加一次性星点粒子，setTimeout 200ms 移除
- **代码量**：~30 行

#### B5 · ChatInput 发送反馈

- **拍板方案**：方案一「星点飞升」
- **当前问题**：按 Enter 后无任何视觉确认
- **新设计**：
  - 发送瞬间，3-4 颗星点从输入框中心向上飞散
  - 飞散角度：随机 -30° 到 +30°
  - 持续时间：200ms 后淡出消失
  - 同时输入框内容清空（当前已有）
- **实现**：onSubmit 时创建绝对定位星点元素，CSS animation 控制飞散轨迹
- **代码量**：~40 行

### 高频 · 每天 N 次

#### B2 · Button 按压反馈

- **拍板方案**：方案一「星点迸射」
- **当前问题**：仅 3D 阴影下沉
- **新设计**：
  - 保留现有 hover translate + 阴影变化
  - **新增**：mousedown（active）时，按钮边缘迸发 3 颗星点
  - 星点方向：向上及两侧飞散
  - 持续时间：200ms
  - **约束**：仅在 primary 按钮上触发，ghost 按钮不触发
- **实现**：复用 B5 的星点粒子组件，调整方向为向四周迸射
- **代码量**：~25 行

#### B3 · Input 聚焦效果

- **拍板方案**：方案一「星点汇聚」（调整版）
- **当前问题**：scaleY(1.05) + border 变色
- **新设计**：
  - **保留现有**：scaleY(1.05) + scaleX(1.02) + border-ember（完全不动）
  - **新增**：首次聚焦时，2-3 颗星点从输入框四周缓慢飘向光标位置
  - 汇聚时长：300ms，到达光标后消失
  - **约束**：仅在首次聚焦时触发，后续输入不再重复
- **实现**：onFocus 时检测是否已触发过，创建星点元素做向心运动，scale 动画保持原样
- **代码量**：~35 行（星点部分）

#### A2 · Home → Study 进入学习

- **拍板方案**：方案五「静水深流」
- **当前问题**：瞬间跳切
- **新设计**：
  - 点击「开始学习」或主题后，从点击位置泛起涟漪
  - 涟漪：ember 色同心圆，向外扩散，透明度递减
  - 涟漪扩散过程中，Home 页面 opacity 渐降至 0.3
  - Study 页面从下方滑入（translateY 20px→0，opacity 0→1）
  - 总时长：900ms（涟漪 300ms + 页面过渡 600ms）
- **实现**：涟漪用 CSS radial-gradient + scale 动画，页面过渡用 React state + CSS transition
- **代码量**：~50 行

#### A3 · Study → Home 结束返回

- **拍板方案**：方案一「星点归巢」
- **当前问题**：瞬间跳切
- **新设计**：
  - 按 ESC 或完成学习后，Study 页面中的星点（C1 的旋转星点）向上飘散
  - 4-5 颗星点飞向屏幕顶部各个位置，opacity 渐降至 0
  - 同时 Home 页面从下方淡入
  - 隐喻：「学习结束，星光归位」
  - 总时长：700ms
- **实现**：在 Study 页面卸载前触发星点飞散动画，Home 页面同时淡入
- **代码量**：~40 行

#### A4 · 模态框打开/关闭

- **拍板方案**：方案一「星点聚合」
- **当前问题**：直接出现/消失
- **新设计**：
  - **打开**：遮罩淡入（opacity 0→0.75，200ms）→ 模态框 scale(0.9)→scale(1) + opacity(0→1)（300ms）→ 边缘 2 颗星点闪烁 200ms
  - **关闭**：模态框 scale(1)→scale(0.95) + opacity(1→0)（200ms）→ 遮罩淡出（200ms）→ 2 颗星点从中心飞散
  - 隐喻：「从虚空中凝结出对话空间」
- **实现**：CSS transition + 状态控制，星点用一次性粒子
- **代码量**：~60 行

### 中频 · 每天数次

#### D1 · StudyLibrary 折叠面板展开/收起

- **拍板方案**：方案一「星帘垂落」
- **当前问题**：瞬间切换，无过渡
- **新设计**：
  - **展开**：max-height 从 0 过渡（300ms ease-out）+ 内容 opacity 0→1（stagger 50ms 每行）
  - **新增**：展开瞬间，面板顶部有 1-2 颗星点闪烁
  - **收起**：max-height 回 0（200ms），无星点（避免双向疲劳）
- **实现**：CSS max-height + opacity transition，星点用一次性粒子
- **代码量**：~30 行

#### D3 · GroupRibbon 分组 Tab 切换

- **拍板方案**：方案一「星光滑轨」
- **当前问题**：瞬间切换，无滑动
- **新设计**：
  - 活跃标签 pill 背景有一个微型的「星点指示器」——2 颗小星点跟随活跃标签滑动
  - 切换时：星点从旧标签位置滑动到新标签位置（250ms ease-out）
  - 同时内容区域 cross-fade（opacity 过渡 200ms）
  - 隐喻：「星光标记你的位置」
- **实现**：用 CSS transition 控制绝对定位的星点元素的 left 属性
- **代码量**：~40 行

#### D2 · GroupRecCard 推荐卡片 Hover

- **拍板方案**：方案一「星尘浮游」
- **当前问题**：hover 边框变色 + 色条加宽
- **新设计**：
  - **保留**：现有 hover 边框（ember/50）+ 色条加宽
  - **新增**：hover 时卡片边缘浮现 3 颗微弱星点
  - 星点位置：右上角 1 颗（ember）、左下角 1 颗（parchment）、右侧中间 1 颗（ember）
  - 星点 opacity：0.3→0.6，300ms
  - 隐喻：「灵感卡片被星光触碰」
- **实现**：CSS :hover 伪元素或绝对定位 div，opacity transition
- **代码量**：~25 行

#### B6 · Toast 通知

- **拍板方案**：方案一「星点淡入」（本轮限定错误态）
- **当前问题**：仅入场 fadeInDown，无退场动画
- **新设计**：
  - **入场**：fadeInDown 200ms + 顶部边缘 2 颗星点闪烁 300ms
  - **退场**：fadeOutUp 200ms（新增）
  - **错误态**：✕ 图标 + wine 色背景（保持现有）
  - **成功态**：本轮不新增，保持现有静默行为
  - 停留时长：保持现有 2s
- **实现**：Toast 组件增加 exit animation，星点用一次性粒子
- **代码量**：~30 行（仅退场动画 + 星点）

> **注**：成功态 Toast（归档成功等）可在后续迭代中补充，本轮聚焦锦上添花。

#### C2 · 「正在浮现…」灵感加载

- **拍板方案**：方案一「星云旋转」
- **当前问题**：旋转 spinner + 文字
- **新设计**：
  - 4 颗星点（2 ember + 2 parchment）缓慢旋转
  - 星点之间用微弱的虚线连接，形成「星座」感
  - 周期：3s linear infinite
  - 文案：「正在浮现…」
  - 加载完成后：星点向卡片位置汇聚并消失（与 B4 呼应）
- **实现**：复用 C1 的星点旋转组件，增加 SVG 连线
- **代码量**：~30 行

#### E1 · 空状态「学习库为空」

- **拍板方案**：方案一「星图未启」
- **当前问题**：一行文字「学习库为空」
- **新设计**：
  - 中央展示一个「微型星图」——4-5 颗暗淡星点 + 微弱连线
  - 文案：「你的星空还在等待」
  - 副文案：「开始第一次学习，点亮第一颗星」
  - 按钮：「开始第一次学习」
  - **hover 星图**：星点微微变亮（opacity 0.2→0.4）
  - **点击按钮**：中央星点亮起（ember 色 + glow），然后进入 PreStudy
- **实现**：SVG 或 CSS 绝对定位星点，简单 opacity transition
- **代码量**：~50 行

#### C3 · Session 文件加载

#### D4 · SessionViewer 打开/关闭

  - **打开**：遮罩淡入 + 查看器 scale(0.9→1) + 边缘星点闪烁
  - **关闭**：反向动画

#### F1 · 学习报告展示

- **新设计**：
  - **与「记忆凝结中」衔接**：归档动画结束后，报告以「卷轴」形式展开
  - 初始：一个窄条（仅显示标题）
  - 展开：高度从 40px → 自动高度（800ms ease-out）
  - 内容在展开过程中 stagger 淡入
  - 隐喻：「记忆如古卷，缓缓铺陈」

#### F2 · 复习模式确认

- **拍板方案**：方案一「星火重燃」（闪屏版）

- **新设计**：
  - 点击「复习」后，屏幕中央出现短暂的全屏遮罩（200ms）
  - 遮罩中央：一颗星点从暗淡到 glow 亮起
  - 文案：「重温这颗星」（主题名 + 日期）
  - 隐喻：「这颗星还在，只是光芒渐弱，现在重新点亮它」
  - **不阻断流程**：星点亮起后立即进入 PreStudy → Study，用户感知为过渡效果
- **实现**：在 openPreStudy 调用前插入 200ms 闪屏动画，不增加确认步骤
- **代码量**：~35 行

## 三、统一组件清单

以下组件可在多个交互中复用：

### 3.1 StarParticle（星点粒子）

```tsx
// 一次性星点粒子，触发后自动移除
interface StarParticleProps {
  count: number;        // 星点数量 2-4
  origin: 'center' | 'bottom' | 'edge';  // 发射起点
  direction: 'up' | 'outward' | 'scatter'; // 飞散方向
  color: 'ember' | 'parchment' | 'mixed';
  duration: number;     // 动画时长 ms
}
```

### 3.2 StarOrbit（星点旋转）

```tsx
// 持续旋转的星点组，用于加载/思考状态
interface StarOrbitProps {
  starCount: number;    // 默认 3-4
  radius: number;       // 旋转半径 px
  period: number;       // 周期 ms，默认 2000
  showLines: boolean;   // 是否显示连线（星座效果）
}
```

### 3.3 FadeTransition（淡入淡出过渡）

```tsx
// 通用的 opacity + translate 过渡
interface FadeTransitionProps {
  direction: 'up' | 'down' | 'left' | 'right';
  duration: number;
  children: ReactNode;
}
```

## 四、技术约束

### 4.1 性能

- 所有动画使用 `transform` 和 `opacity`，避免触发 layout/paint
- 星点粒子使用 `will-change: transform, opacity`
- 动画结束后立即移除 DOM 节点，避免内存泄漏
- 低端设备降级：减少星点数量或禁用非必要动画

### 4.2 可访问性

- 所有动画遵循 `prefers-reduced-motion` 媒体查询
- reduced-motion 时：所有动画变为 instant（opacity 直接切换，无位移）
- Toast 通知保持屏幕阅读器可读

### 4.3 实现顺序建议

按优先级从高到低：

1. **Phase 1（核心体验）**：C1、B4、B5、B2、B3
2. **Phase 2（页面过渡）**：A2、A3、A4
3. **Phase 3（数据展示）**：D1、D3、D2、B6、C2
4. **Phase 4（边缘场景）**：E1、C3、D4、F1、F2
