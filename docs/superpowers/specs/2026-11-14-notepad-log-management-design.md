# 记事板已完成条目管理设计（2026-11-14）

## 目标

已完成时间线支持「恢复待办」与「删除」。恢复用于纠正误打勾；删除用于清理不再需要的档案，两者不混用语义。

## 交互链路

- 已完成条目 hover 显示「恢复待办」「删除」，按钮点击不触发行展开或评论输入。
- 恢复不弹确认：条目移到待完成列表首位，保留 id、短标题、正文、分类、创建时间和评论，移除 `resolvedAt` / `source`；待完成页不新增评论区，重新完成后评论重新出现在档案中。
- 删除弹出既有 `ConfirmDialog`，明确条目及其评论将永久删除；确认后只修改 `notepadLog`，不影响其他待办。
- 删除或恢复后清理该行的展开、评论编辑临时状态；面板尺寸、字号、当前 tab 与其他条目不变。

## 状态与持久化

`NotepadComment[]` 可选字段上移到 `NotepadItem`，`NotepadLogEntry` 继续继承。store 新增 `restoreNotepadItem(id)` 与 `deleteNotepadLogEntry(id)`，均递增 `notepadLocalVersion` 并通过一次 `state:patch` 原子写回相关数组，沿用现有刷新竞态防护。

恢复不新增排序字段：由于原待办顺序未入档案，统一放到首位。删除不新增回收站。

## 验证

- store：恢复字段与评论保留、置顶、持久化；删除只移除目标档案；不存在 id 无副作用。
- 组件：按钮 stopPropagation、恢复无需确认、删除取消/确认、评论状态清理。
- 定向 E2E：误完成后恢复回待办，再删除档案并验证重启后的 state。
