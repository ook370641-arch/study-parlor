# 写作专辑墙与共享展示层设计（2026-11-14）

## 目标与已选方向

文章、仓库主区新增专辑墙；分组采用视觉评审选定的 **A · 分区分组墙**。共享展示骨架，但不合并博客、笔记、写作的领域状态与操作语义。

## 用户交互链路

### 文章 / 仓库

1. 用户切到「文章」或「仓库」；无匹配当前 tab 的打开文档，或用户显式返回墙时，主区显示对应专辑墙。
2. 墙按目录分区。每张卡显示封面与标题；hover 显示 Markdown 正文字数，并露出删除、封面生成等操作。
3. 点击卡片或左侧树条目打开编辑器；编辑器左上「← 专辑墙」先保存 dirty 文档，再返回对应来源的墙。
4. 点击生成封面不自动弹窗：卡面进入生成态，完成后显示「待挑选」；再次点击打开三候选，选中后落盘并同步墙与编辑器 frontmatter。
5. 删除卡片弹出既有永久删除确认；确认后调用现有 `writingDelete`，刷新树与墙，并清理该文生成封面。墙内删除不得自动打开第一篇文章。

### 笔记 / 博客

- 笔记保留来源筛选、评分、时间/类型/评分排序、书籍章节聚合与下拉、封面生成、候选挑选和左侧书架；新增 hover 字数，不改变既有链路。
- 博客保留「我的 / 全部」、来源筛选、已保存/已读/收藏分组、折叠、组与组内拖拽排序、推荐入口、远程封面和删除语义；只替换展示骨架。

## 分组与排序

- 文章/仓库把目录树展平为「文件实际所在目录」的分区，文章不会同时出现在父组和子组；嵌套组标题显示相对路径，根目录文件归入「未分组」。
- 默认沿用 `writingOrder` 与目录树顺序；每组可折叠，折叠状态按 root 独立且仅会话内保存。
- 排序提供「默认顺序 / 最近修改 / 字数」，只在组内排序，不改变磁盘目录或手动顺序。
- 空组不单独生成卡片；整墙为空时保留左侧新建/导入引导。

## 共享组件边界

新增 `src/components/album-wall/`：

- `AlbumWall`：主区滚动容器、工具栏/空态插槽；`AlbumGrid` 提供统一响应式网格。
- `AlbumCard`：3:4 卡片、键盘打开、封面/标题、hover 信息与顶部/底部操作插槽，可选拖拽事件。
- `AlbumGroupSection`：标题、数量、折叠与可选拖拽事件；博客的 `BlogMineGroupSection` 作为领域适配器继续保留推荐插槽和 test id。

这些组件不读取 Zustand、不调用 IPC。`BlogWall`、`NotesWall`、`WritingWall` 各自准备数据与回调。

## 字数与元数据缓存

- 字数规则：frontmatter 不计；中文按汉字计数，英文与数字按连续词计数，URL 不计。非 Markdown 文件不显示字数。
- `NoteEntry` 增加可选 `wordCount`，笔记扫描已经读取正文，直接派生。
- `WritingTreeNode` 文件节点增加可选 `wordCount`、`mtimeMs`、`coverUrl`。`writing:scanTree` 使用 catalog 的独立 `wallMtimeMs` 缓存确定性元数据；文件未变时不重读正文。
- `wallMtimeMs` 与 AI 摘要使用的 `mtimeMs` 分离，避免字数缓存让摘要漏生成。保存、移动、重命名沿用现有 catalog 迁移；内容变化后下一次扫描重算。

## AI 封面复用与存储

- 候选对话框、生成动画、重复提交保护、SVG 安全校验与渲染共用；笔记现有 IPC 行为保持兼容。
- 写作新增 `writing:generateCovers` / `writing:saveCover`，仅接受 `writing/`、`repository/` 内的 Markdown 文件。
- 写作封面保存到对应 root 的 `.covers/`，文件名包含路径哈希，避免不同目录同名文章冲突；`cover` 相对路径写入原 frontmatter，其他字段与正文不变。
- 沿用原子写入：候选只在内存，选中才写 SVG；frontmatter 更新失败时清理新文件并保留旧封面。非 Markdown 使用类型渐变，不提供 AI 封面。

## 错误与兼容性

- 字数或封面元数据读取失败只让该卡回退，不阻断整棵树；正文与既有 catalog 摘要不被清空。
- 生成失败保留原封面并 toast；保存失败保留候选供重试。删除失败保留卡片并显示错误。
- 不为文章/仓库强加评分、书籍章节或博客拖拽；不新增封面位图依赖，不运行全量 E2E。

## 验证与文档

- 纯逻辑：混合文本字数、缓存失效、目录展平、三种组内排序、旧 catalog 兼容。
- 组件：共享骨架下的博客/笔记回归；写作墙打开、返回、折叠、hover、删除确认、封面三候选与失败恢复。
- IPC：写作封面路径限制、原子保存、删除清理；dirty 文档返回前保存。
- 新增定向 `writing-album-wall.spec.ts` 并维护 `e2e/source-map.json`；运行受影响 Vitest、`node scripts/e2e-changed.js --run --no-retries`、`npm run build` 与 `npm run docs:check`。
