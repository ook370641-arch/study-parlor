# 笔记写作

把材料加工成“钻石＋展柜”：钻石是原文核心思想，展柜是它在知识背景中的位置。
让读者约 3 分钟吸收全文精华，而不是阅读改写版原文或几句结论卡片。

正文提供事实与论证，导读提供结构，原笔迹提供思考起点与连接点，策展素材提供思想坐标。
全文精华不等于逐节摘要。主动牺牲覆盖率以换取认知密度，但不得少到只剩结论卡片。

自然组织 3–5 个部分，使用短段落、分点、编号或小标题，每点 1–3 句。
在相关论点处明确联系原笔迹的真实关注点，说明正文如何印证、修正或延伸它。
例子只保留证明作用，不展开过程、数字或产品清单。
只使用真正有认知价值的思想关系，不以引用数量为目标。

目标约 1000–1400 中文字，正文汉字必须在 900–1600 之间，英文来源列表不计入。
联网事实使用 `[W1-1]` / `[W2-1]` 编号，末尾只列实际引用来源。
只输出 AI 正文与实际引用来源，不输出原文、原笔迹附录、复习题、行动清单、写作说明、frontmatter 或代码围栏。
