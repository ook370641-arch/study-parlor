你正在为"学者夜话"设计续谈主题。请根据学习者在该主题下的历史，推荐 2-3 个具体的续谈方向。

主题：{{topic}}
历史学习记录：
{{reportSummaries}}

【历史记录不足时的处理】
如果历史为空或只有1次（无法引用"第X次报告"）：
- 基于主题本身的核心子模块推荐
- 推荐理由引用"该主题的典型学习路径"
- 优先"深化理解"维度

约束：
1. 每个推荐是独立的、具体子主题。一次 30-45 分钟苏格拉底对话覆盖核心概念。
2. 推荐理由引用历史中的具体线索（如"你在第X次学习提到…"）。历史不足时引用"典型路径"。
3. 推荐之间要有区分度：覆盖深化理解、横向拓展、薄弱环节、前沿联系。
4. 若历史显示某处有明确困惑，优先推荐针对性方向。
5. 首次学习（无历史）时，推荐该 topic 下的 3 个经典入门切入点。

【好推荐的标准】
- **具体且可命名**：学习者可以说"今天我想学[title]"
- **有清晰的学习路径**：单次会话内 AI 能引导覆盖核心概念
- **匹配当前水平**：不推荐已掌握内容，也不推荐远超能力的内容
- **有长期价值**：解释为什么值得花时间

【绝对红线】
- **绝不**推荐已明确表示掌握的内容
- **绝不**推荐需要尚未具备的前置知识的内容
- **绝不**推荐过于宽泛、模糊、无法命名的方向

【维度优先级】（从高到低）
1. **薄弱环节补救**
2. **深化理解**
3. **横向拓展**
4. **前沿联系**

> 绝对红线优先于维度优先级。即使维度优先级很高，也必须通过三条红线检查。

【格式强制要求】
- 只输出 JSON 数组，不要任何其他内容
- 不要 markdown 代码块
- 回复必须直接以 [ 开头，以 ] 结尾
- 每个对象包含四个字段：`title`、`context`、`rationale`、`benefit`。
  - `context`：学习现状——引用历史中的具体线索说明当前水平（1-2句）
  - `rationale`：推荐理由——为什么这个方向合适，单次学习能覆盖什么（1-2句）
  - `benefit`：长期收益——掌握后有什么实际能力变化（1-2句）
  - 某部分无内容时用空字符串 `""`，不要省略字段

示例：
[{"title":"Q-Learning收敛性证明","context":"你在第3次报告中提到'对收敛条件理解不透彻'，只停留在直观感受层面。","rationale":"从贝尔曼最优性方程出发，一步步推导收敛所需的数学条件，正好填补你当前的理解缺口。","benefit":"掌握收敛性证明后，你能判断算法何时会收敛、何时需要调整参数，这是从'会用'到'懂原理'的关键一跃。"}]
