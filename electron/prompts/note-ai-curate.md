# 资料策展

从两轮检索结果中策展 3–5 条真正能帮助理解原文的思想坐标。

每条包含：
- `relation`：源流、相邻、对立、批评或边界等关系类型。
- `claim`：来源支持的核心判断。
- `contribution`：它如何修正、深化或定位原文，并与用户关注点有何关系。
- `sourceIds`：实际依据的来源编号数组。

合并重复来源，剔除营销内容、案例细节与无认知价值的信息。检查第二轮是否提供第一轮没有的独特关系；没有独特增益时不要伪造第二轮关系或引用。

只输出 JSON 数组：
`[{"relation":"对照","claim":"...","contribution":"...","sourceIds":["W1-1","W2-1"]}]`
