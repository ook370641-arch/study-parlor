# 学者夜话：我做了一个本地AI学习伴侣，想解决三个困扰我很久的问题

凌晨两点，你打开了ChatGPT。

手指悬在输入框上。你想学点什么，可能是Transformer的注意力机制，可能是行为经济学的前景理论，可能只是想知道"熵增"到底是怎么回事。但大脑一片空白。你甚至不知道该问什么。

最后你输入了那句万能开场白："给我一个详细的解释。"

AI开始滔滔不绝。你读了两三段，觉得"好像懂了"，关掉窗口。一周后，什么都不记得了。

如果你也有过这种体验，下面的内容可能会让你感兴趣。

---

## 先说说这三个问题

**第一个：不知道怎么提问。**

每次想学习，先花十分钟纠结prompt。直接问"什么是Transformer"，得到的回答太泛，像教科书目录。写一堆限定条件，又像是给AI布置作业。学到最后，想问题花的精力可能比学习本身还多。

**第二个：聊完就忘。**

和AI聊了一个小时，感觉今天收获不小。关掉窗口，知识就蒸发在空气里。没有笔记，没有归档，没有复习。一周后你甚至想不起来当时聊了些什么。

**第三个：纯文本太枯燥。**

大段的解释性文字，没有故事感，没有情绪起伏，没有那种"啊，原来如此"的顿悟时刻。看完一段，忘记一段。学习效率就是一个漏斗，上面倒进去，下面漏出来。

这三个问题，说穿了都是一件事：AI帮你获得了信息，但没有帮你建立记忆。

---

## 我做了什么

花了三个月，做了一个东西。名字叫学者夜话（Study Parlor）。

它是一个本地运行的AI学习伴侣。有长期记忆，有自己的教学方法，还有一套仪式感。不是普通的聊天工具，是一个学习系统。

下面说说我个人觉得最有意思的几个设计。

---

## AI问你答，不是AI答你问

普通的AI对话，是你问它答。学者夜话把这个关系倒过来了：你选主题，AI先问你问题，了解你的起点，然后通过一连串有针对性的提问，引导你自己发现答案。

它不会直接告诉你答案。永远不会。它只会问出那个让你"啊，原来如此"的问题。

这背后是Bloom 2 Sigma效应——一对一苏格拉底式辅导的掌握度比普通课堂高两个标准差。具体实现上，应用内置了一套Prompt装配链：学习者基座设定、本次学习方向、模式选择（探索新知还是复习检测）、难度调节、个人画像，五层拼接，每次对话都是量身定制的。

你可以调整"审讯强度"（高中低三档）和"腔调"（温和、中性、犀利）。选温和模式，AI像耐心学长；选犀利模式，它会追着你问到你答不上来为止。

---

## 每次学习结束，自动归档

这是我最在意的功能之一。

每次夜话结束，AI自动生成一份结构化学习报告，包括主题、学习要点、认知缺口、掌握度检验、未来发展建议。纯Markdown格式，保存在你的本地文件夹里。

文件组织是三层结构：分组 → 主题 → 会话。比如你在"AI"分组下有个"Transformer"主题，可能已经聊了三次（s1、s2、s3），每次一份独立Markdown，又都属于同一个主题。随时打开查看、修改、导出。

所有内容都是纯文本，存在你自己的文件夹里。哪怕明天卸载应用，知识库依然可用任何编辑器打开。没有云端绑架。

---

## 复习不是重读，是考试

回到一个旧主题，学者夜话不会让你"再看看上次学了什么"。它会直接进入复习模式：基于你的笔记出题考你、找薄弱点、给掌握度评分，然后把复习记录追加在原文件末尾。

另外，当你回到一个主题时，AI会根据历史记录推荐三个"续谈方向"。比如你已经学完了Transformer基础架构，它可能会推荐"多头注意力的数学原理"、"位置编码的演进"、"与RNN的对比分析"。每次打开，面前都有一条清晰的路。

---

## 我最喜欢的功能：寓言

学习结束后，你可以让AI把刚才的内容改写成一则寓言故事。不是简单比喻，是一个完整故事，有角色、情节、冲突、转折。

关键是，概念名称会刻意延迟揭示。故事先在你脑中建立一个情感锚点，等你感到"原来如此"的时候，再点破隐喻。故事里哪个角色对应什么概念，哪个情节对应什么原理，一一对应。

可以选风格标签：赛博朋克、存在主义、温柔，或者自定义描述。AI会根据你的选择写出一则1500到3000字的完整寓言。

这个功能的灵感来自认知心理学里的"叙事传输效应"——人在故事中的记忆留存率比纯信息高得多。

---

## 我不想再做"又一个白色背景的AI工具"

UI参考了Disco Elysium（极乐迪斯科）的风格。深褐色主色调，米色羊皮纸质感的文字，暖橙色余烬般的按钮高亮。打开应用，全屏油画背景，Mark Rothko的色域绘画或Guy Billout的超现实插画，上面有暗角遮罩，像是深夜书房的氛围。

内置了120多张精选画作。三个界面（封面、主页、学习页）可以分别设不同背景。也可以往Pictures文件夹放自己的图片，重启后随机切换。

语言体系也是沉浸式的：学习叫"夜话"，记录叫"笔录"，归档叫"封存"，删除叫"焚毁"，开始叫"落印"，取消叫"作废"。这些不是装饰，是为了让你感到这不是在用一个工具，是在一盏孤灯下和一个耐心的档案管理员深夜长谈。

启动时的墨滴扩散动画、AI思考时的星星轨道旋转、按钮hover时的光扫效果，这些细节不是为了炫技，是为了让这段学习时光值得被认真对待。

## 开源和扩展

学者夜话完全开源，MIT协议。代码在GitHub上，可以自己编译、修改、扩展。

内置了两个Claude Skill（study和fable），你可以在Claude Agent中随时调用它们进行学习，结果自动同步到学习库目录。这在需要上下文的场景特别有用，比如在复习实习项目代码时，可以直接在Agent里边看代码边学习，结束后报告自动归档。

---

## 怎么用

需要Node.js 20+。

```bash
git clone https://github.com/ook370641-arch/study-parlor
cd study-parlor
npm install
# 复制.env.example为.env，填入你的Kimi API Key和学习库路径
npm run dev
```
