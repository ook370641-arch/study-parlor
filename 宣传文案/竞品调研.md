## 0. 一页总控

**四家做的是同一件事 —— 把无法被直接读取的复杂文档，变成 AI 能落地生产的结构化数据。**

**这不是四选一：解析、抽取、管道、平台四个模块家家都在做，区别只在「立身之本」—— 各自从哪个点起家、把哪个点做到最硬：**

- **Reducto 以解析单品立身**：r-1 把单页质量做到出圈；
- **Unstructured 以 ETL 管道立身**：开源库 + 连接器矩阵跑通全链路；

- **Extend 以生产平台立身**：工作流 + 评测台，层二最完整。

**共同动作**：2026 年四家都在从层一（卖确定性工具）往层二（编排整条文档流程）收敛 —— 出身不同，去向相同。

## 1. Extend.ai — 「把文档处理当成生产系统来卖」

### 一、核心定位：AI Agent 时代的生产级文档数据中台

Extend.ai 本质是面向 AI 应用与企业自动化的文档数据基础设施，而非传统 OCR 工具。它将 PDF、合同、票据等非结构化文档转化为可直接投产、可置信、可溯源的结构化数据，精准解决两个根因：通用大模型 / OCR 效果达不到生产标准、企业自研流水线成本高。

它的定位有两个核心锚点：

- **技术锚点：生产级**：主打真实生产场景的稳定性与可用率，而非标准测试集上的演示级准确率；
- **客户锚点：自下而上渗透**：以技术团队为切入点，先解决开发者效率问题，再逐步渗透到企业核心业务，最终成为企业级文档自动化底座。

### 二、客户分层：从开发者到大型企业的渗透路径

采用技术驱动的自下而上策略，客单价与客户体量逐级升级：

1. **种子层：开发者、ML 团队与 AI 初创**

   核心诉求是快速接入、无需自研，靠开箱即用的 API、多语言 SDK、预置行业模板极致降低接入门槛，几分钟就能把文档能力嵌入自身产品。
2. **增长层：成长型科技独角兽**

   核心群体：覆盖金融科技、医疗、采购等赛道的头部企业，用标准化方案替代自研工具，降低长期维护成本。
3. **顶层：财富 500 强大型企业**

   主打合规、数据安全与大规模部署能力，服务各行业头部企业。

### 三、核心场景与行业方向

#### 三大核心生产场景

1. **AI Agent 文档感知底座**：为各类 AI Agent 提供结构化文档输入，适配主流 Agent 生态，从根源避免大模型读文档的幻觉、乱序、上下文超限问题。
2. **端到端文档自动化流水线**：从文档上传到分类、提取、路由全链路可嵌入客户自有应用，替代企业零散工具与自研脚本。
3. **文档反欺诈校验**：差异化新赛道，可检测 AI 生成 / 篡改、内容擦除伪造、签名后修改等问题，命中金融、合规、背调等高真实性要求场景。

#### 行业方向

聚焦文档密集、高价值、高合规的垂直赛道，覆盖金融科技、医疗健康、物流供应链、地产、HR 背调、采购 SaaS 等领域。

### 四、产品能力与差异化优势

#### 1. 全链路能力边界

核心覆盖解析、提取、分类、拆分、填写、校验、工作流七大模块，支持 35+ 文件格式，所有结果附带多层置信度评分与原文位置溯源。

#### 2. 技术路线：工程化优先，而非单一模型

不走 “自研大模型” 的同质化叙事，采用「自研专用小模型 + 前沿基础模型混合调度」的务实路线，提供低延迟实时、成本优化批量、最高精度三档模式，搭配多轮复核 Agent 保障生产稳定性。

核心竞争力在工程化套件：自动优化提取规则的 Composer Agent、可视化效果评测平台、置信度审核机制，把文档解析效果当成可迭代的软件质量来管理。

#### 3. 三大独有壁垒

- **评测回归平台化**：让非算法背景的业务专家也能参与效果迭代，降低优化门槛；
- **Verify 文档反欺诈**：率先切入 AI 时代文档真伪校验的空白赛道；
- **「生产级」价值叙事**：跳出 “比模型参数” 的内卷，主打 “可直接上线、稳定可控”，直击企业 “Demo 好看但落地难” 的痛点。

### 五、商业模式与合规

- **收费模式**：SaaS 订阅 + 按用量阶梯计费的组合模式。
- **部署方式**：支持美 / 欧区公有云、客户私有 VPC 部署、混合部署。

### 六、市场推广：技术驱动、自下而上

1. **开发者自助接入**：完善的 API、SDK、CLI 与 MCP 标准接入，开发者可自助注册集成，实现产品自传播。
2. **标杆案例口碑**：用头部客户的真实业务成果背书，打动同层级客户。
3. **专业评测立权威**：推出 RealDoc-Bench 真实生产文档评测集，公开对比通用方案，建立技术口碑。
4. **Agent 生态借势**：深度融入主流 Agent 生态，作为文档能力底座随生态触达更多终端客户。

---

整体来看，Extend.ai 走的是「技术切入 → 场景深化 → 企业升级」的清晰路径，乘着 AI Agent 的浪潮，把文档处理从单一识别工具，升级成了企业级的智能基础设施。

## 2. Reducto — 「用解析质量起家，用一体化模型发起价格战」

### 一、核心定位：为 AI 团队打造的 Agentic 文档平台

Reducto 自称「The Agentic Document Platform for AI Teams」，本质是一家以解析质量出圈、再向全生命周期文档平台扩张的 API 公司。它把密集表格、手写件、扫描传真等高难度版面转成 LLM-ready 的结构化数据，解决的是 AI 团队「通用解析器读不了真实脏文档」的问题。

它的定位有两个核心锚点：

- **质量锚点：以「最难的页」立口碑**：不拼标准文档的演示分，专攻嵌套表格、手写批注、低质扫描等其他管线掉队的长尾场景；
- **价格锚点：透明即诚实**：2026 年发布自研 r-1 一体化模型，端到端解析 1 美分 / 页 all-in，把价格表直接摆到台面上。

### 二、客户分层：从初创到 Fortune 10

客户体量随产品成熟逐级上探，官网原话「Helping everyone from startups to Fortune 10 enterprises」：

1. **种子层：AI 初创与开发者**

   Standard 档自助开通、按量付费，注册即送 150 美元额度，几分钟跑通第一次解析。
2. **增长层：成长期 AI 公司**
3. **顶层：Fortune 10 大型企业**

### 三、核心场景与行业方向

#### 三大核心场景

1. **高难度版面解析**：密集表格、手写、扫描件、传真、批注、多栏排版，转成保留版面与阅读顺序的结构；
2. **文档进门自动分拣**：以前是人打开看一眼、再分发给不同部门；现在系统自动判断这是什么文件（发票 / 合同 / 病历）、把混在一起的文件包拆开、送到对应处理流程，不用人管；
3. **文档可溯源**：把长文档按标题、表格、段落的结构切成小块（不是机械地每 500 字切一刀），每块都标注它在原文第几页、什么位置；大模型回答时能直接调出相关内容，还能在原文件上把出处框出来给人核对。

#### 行业方向

官网铺出金融、保险、法务、医疗、政府、建筑、物流等 8 个行业页，全部是文档密集且对错误零容忍的赛道。

### 四、产品能力与技术路线

#### 1. 全生命周期能力边界

Classify → Parse → Extract → Split → Edit → Pipelines 六件套覆盖文档从进门到改写的完整链路，支持 30+ 文件类型、100+ 语言，每个结果都带边界框引文。另有 Studio 可视化工作台：在浏览器里搭管线、测效果、一键部署，还能在引文查看器里逐框核对原文。

#### 2. 技术路线：从「多工具拼管线」反转为「单模型一次过」

早期 Parse 走 multi-pass 路线，OCR、版面检测、视觉语言模型分阶段串联；2026 年的 r-1 反转成 unified full-page model —— 文字、表格、图表、版面、格式、grounding 一个全页模型一次完成，错误率比旧 agentic 管线再降 20%，成本最多降 6 倍。需要自定义提示或高级图表抽取时，还能叠加 agentic 处理做增强；更小的 r-1 mini 与按页自动路由也已在路线图上。

### 五、商业模式：价格战是明牌

- **公开价目表**：r-1 Parse 10 美元 / 千页，Extract 20 美元、Deep Extract 40 美元，Split 20 美元、Classify 7.5 美元，Edit 60 美元（预填页 15 美元），批量处理再减 20%；
- **大客户定制**：Growth / Enterprise 按年度页数承诺议价，Enterprise 独占 VPC、气隙 on-prem、定制微调与 24/7 oncall；
- **抢客动作**：从其他解析器迁移最高补 5,000 美元；另设创业计划与 YC 专属价。

部署弹性是四家最大之一：SaaS、混合 VPC、全 VPC、气隙 on-prem 四档；零数据保留（24 小时删除）、EU/AU 数据驻留、最高 99.99% SLA；安全资质具备 SOC 2 Type II、HIPAA。

### 六、市场推广：质量口碑 + 价格锚点

1. **Bakeoff 挑战文化**：公开邀请客户拿自己的文档做横向对比，compare 页把 LlamaParse、Textract、Extend 等十余个对手逐一列出；
2. **价格锚点即传播事件**：1 美分 all-in 本身就是行业新闻，等于宣告解析成本曲线已被打穿；
3. **内容营销**：大量 cookbooks、processors 与工程博客降低上手门槛；
4. **Agent 生态借势**：MCP、CLI、Agent Guide 全套工具链，让文档能力随 Agent 生态分发。

---

整体来看，Reducto 走的是「解析质量起家 → 一体化模型压价 → 全平台扩张」的路径。它与合合的同构度最高 —— 同样从层一的解析单品起家、同样主动压低价位、同样向层二平台长，是 DocFlow 最值得细挖的同构对照组。

## 3. Landing AI — 卖『可证明的准确』

### 一、核心定位：把「可证明的准确」做成产品

Landing AI 由吴恩达创立，官网 brand 为「Agentic APIs for Intelligent Document Processing」，核心产品 ADE（Agentic Document Extraction）。它的卖点不是最便宜，而是最可审计：每个抽取字段都附带置信度，以及页码、坐标组成的证据链，让企业能证明结果从哪来，而不只是相信结果。

两个核心锚点：

- **证据锚点：每个字段都能回指原文**：不是「模型说对了」，而是「你可以翻到那一页、那个位置自己核对」；
- **客户锚点：服务买不起错误的行业**：金融、医疗、保险这类一个字段出错就是真金白银损失的场景，是它的主战场。

### 二、客户画像：强合规行业的企业买家

与 Extend、Reducto 相比，Landing 的买家更偏企业业务与合规部门，而非纯开发者，官网自称 50+ 企业客户：

1. **金融服务**：贷款与信贷承销、KYC、监管报送；
2. **保险与医疗**：理赔单据、病历与临床内容；
3. **能源、法务、物流**：各类高变异、强审计的文档流程。

> 一句客户证言点透定位：「Trust is the product. Accuracy alone isn't enough at enterprise scale — what matters is provenance, traceability, and control.」（某 Fortune 100 金融服务公司数据与分析负责人）

### 三、核心场景

1. **高变异文档自动抽取**：字段必须回指原文（页码 + 精确坐标），结果才能进审计流程；
2. **低置信度自动转人工**：置信度低于阈值的字段自动路由人工复核，不赌「全对或全错」；
3. **失败案例闭环**：错误被捕获、审计、系统性回流，靠更好的数据而非更大的模型提升精度。

### 四、产品能力：三 API + 双模型

#### 1. 三个 API 构成完整链路

- **Parse**：把 PDF、图片、Office 文档、表格转成阅读顺序 Markdown 与层级化结构，每个块带坐标；
- **Extract**：按 schema 从 Markdown 抽取指定字段；
- **Ground**：把每个字段映射回它引用的原文块，返回块 ID、页码与边界框，同步调用、不消耗额度。

#### 2. 双模型分档，快照可锁定

- **DPT-3 Pro**：默认档，质量最高，覆盖扫描件、手写、非拉丁文字、数学公式与复杂表单；
- **DPT-3 Verity**：面向数字原生文档，延迟更低、额度省约三分之二，带词级置信度。

模型支持锁定具体快照（如 2026-07-10 版本），解析结果长期一致 —— 这对审计场景是刚需：同一份文档今天和半年后得到同样的输出。

### 五、技术路线：vision-first 自研视觉模型

不走「调用通用 VLM」的捷径，Landing 坚持自研专用视觉模型，配合 agentic 编排 —— 官网原话「Planning, deciding, and verifying until quality thresholds are met」，系统自己规划、决策、校验直到质量达标。性能上可做到每分钟数千页、单页 2 秒内返回。这是吴恩达 data-centric AI 理念的产品化：精度从精心治理的数据与失败回流中来。

### 六、商业模式与合规

- **信用点计费**：1 美元购买 100 credits；Explore 档自助付费（送 1000 免费点），Team 档 250 美元 / 月起，Enterprise 定制；
- **云市场渠道**
- **部署**：支持云、on-prem、虚拟私有部署与零数据保留。

### 七、市场推广：创始人 IP + 审计叙事

1. **创始人 IP 引流**：吴恩达的行业声量是最硬的信任状；
2. **Playground 免费试用**：浏览器上传即跑，无需写代码；
3. **合规双线说服**：安全页单独成页，同时面向采购与风控；
4. **数字与生态**：1B+ 文档处理量背书，同步补齐 ADE Skill、CLI、MCP 等 Agent 接入物料。

---

整体来看，Landing AI 把「证据链 = 审计就绪」做成了四家中唯一的定位，直接切入监管行业；它自身从工业视觉 LandingLens 整体迁移到文档赛道，也是「能力迁移 → 赛道切换」的活样本。

## 4. Unstructured — 「开源起家卖文档 ETL，正在长成企业 GenAI 数据层」

### 一、核心定位：企业 GenAI 栈的数据预处理层

Unstructured 一句话讲清自己：「We structure your unstructured data」。它做的是文档 ETL 管道 —— 把几十种格式的文档在进入 RAG、向量库之前完成清洗、结构化、分块、向量化与装载，开源库与商业平台 Transform 双轨并行，正在卡位企业 GenAI 技术栈的「数据预处理层」。

两个核心锚点：

- **广度锚点：没有打不开的格式**：开源库支持 65+ 文件类型，20+ 数据源、20+ 目的地，格式覆盖是四家最宽；
- **开源锚点：四家中唯一 open-core**：产品本体开源，靠社区拉新、靠托管平台变现。

### 二、客户分层：两类买家

1. **企业数据 / AI 平台团队**：替换自研的数据管线，让工程师不再为「数据管道工」烧时间；
2. **大平台本身**：SAP、IBM、Intel、Teradata、Uniphore 直接把它内嵌进自家产品做预处理。

> SAP 全球 CTO 的证言：「我们评估了十家供应商，最终选择 Unstructured，在其平台上以多年期合作共建 SAP 的 AI 未来。」Teradata 则把它原生装进 Enterprise Vector Store。

### 三、核心场景与行业方向

核心场景一句话：**文档进模型前的全部脏活**。官网 FAQ 讲得直白：「Parsing is the easy part. The real work is connecting to your sources, then chunking, embedding, and loading... A parser handles one file. Unstructured runs the whole pipeline.」

行业落点包括：金融贷款字段抽取与研究 copilot、保险 ACORD 表单与理赔、法务合同条款、生命科学论文、制造业技术手册。

### 四、产品能力：三层产品矩阵

1. **Transform（MCP / API）**：上传文档，系统自动选择解析策略，返回 Markdown 或结构化字段，无需自己调模型、搭管线；
2. **Pipelines（ETL）**：40+ 连接器对接 S3、SharePoint、Snowflake 等源与各类向量库，自带变更检测、增量处理与定时调度；
3. **Foundation（早期访问）**：面向 Agentic 企业搜索的单个 MCP，给 Claude、Cursor、Codex 提供全语料库的持续检索，官方称检索精度提升 14 倍、Agent 轮次减少 85%、成本降至十分之一。

需要说明的口径：65+ 文件类型是开源库的广度，托管 Transform API 当前支持 9 类核心格式，平台口径为 50+。

### 五、技术路线：open-core + 策略货架

开源库（Apache-2.0，GitHub 15.6k star，30+ 文档类型各自实现真实解析器）是获客入口，托管平台承接生产负载。平台提供 Auto / Fast / High-Res / VLM 四种分区策略，按页面难度自动换挡；分块、NER、生成式 OCR、图表描述、embedding 模型均以货架形式提供，客户按需挑选。它的「source → parse/chunk/embed/extract → destination」抽象，与合合 xParse Pipeline 完全同构。

### 六、商业模式与合规

- **三档公开定价**：Free（1 万页免费）、Pay-As-You-Go（每页 1.5 美分）、Business（专属实例或 VPC，定制议价）；
- **部署弹性**：SaaS、专属实例、自有 VPC、裸金属均可。

### 七、市场推广：开源漏斗 + 平台伙伴

1. **开源社区拉新**：开源库即最大漏斗，开发者用起来再向平台转化；
2. **平台伙伴联合销售**：SAP、IBM、Intel、Teradata 首页互背书，借大平台触达终端客户；
3. **合规背书**：FedRAMP 直接打开政府市场；
4. **自评与内容**：首页列出表格准确率、内容准确率、最低幻觉率三项第一，配合 benchmarks、insights 等内容建立技术口碑；Agent 生态同样跟进 MCP 与 agent-guide。

---

整体来看，Unstructured 是四家中唯一 open-core、唯一 FedRAMP、唯一把「连接器矩阵」当主卖点的公司；它的管道抽象与合合 xParse Pipeline 最为接近，是除 Reducto 之外最值得对照的参照。

## 5. 横向差异整合

四家不是「四选一」，而是各有一个把它做到最硬的立身之本；真正的差异集中在出身、收钱、交付形态、独门武器这四件事上。

### 5.1 比出身：四家各押一个点，合合两层一开始就都有

- **Reducto 押「单页解析」**：把最难的页（手写、传真、嵌套表格）做到出圈，靠解析质量立身；
- **Unstructured 押「管道宽度」**：开源库 + 连接器矩阵，把「什么格式都能接、哪里都能送」做到四家最宽；
- **Landing 押「字段证据链」**：每个字段都能翻回原文核对，把「可审计」做成产品；
- **Extend 押「生产平台」**：工作流 + 评测台，把层二的完整度做到最高。

**合合不是「从层一往上长」，而是两层一开始就都有**：层一 xParse 做确定性工具，层二 DocFlow 做端到端流程 —— 海外四家是「先有一个点、再补另一个」，合合是「两层同时经营」。

### 5.2 比收钱：一个打价格战、一个送开源、一个卖「证明」

- **Reducto 明牌打价格战**：r-1 端到端解析 1 美分 / 页 all-in，把价格表直接摆上台面；
- **Unstructured 用开源做漏斗**：开源库免费、1.5 美分 / 页，先让人用起来再向平台转化；
- **Landing 卖「可证明的准确」**：信用点计费、偏企业销售，价格不是它的卖点，「能审计」才是；
- **Extend 订阅 + 用量**：案例偏大客户，靠生产平台的完整度收钱。

**合合是两套计价并存**：xParse 按页（0.1 / 0.3 元每页、新用户 50 页免费），DocFlow 按项目 / 席位 —— 层一卖工具、层二卖流程，和海外的分层逻辑一致。


### 5.3 比交付形态：海外卖给开发者，合合直接经营业务流程

这是合合和海外**差异最大的一点**：

- **海外四家的层二，买家是开发者**：编排的是软件流水线（API → Job → webhook），交付的是「让你自己搭 Agent 的接口」；
- **合合 DocFlow 的买家是企业业务部门**：直接给工作空间、文件类别、字段与表格、印章与手写、审核规则库、iframe 嵌入、多租户，交付的是「一条能跑的业务流程」，卖的词是降本增效。

层的维度吻合，但**一个卖零件、一个卖整条流水线**。

### 5.4 比独门武器：每家都有一个别人没有的点

- **Reducto**：r-1 单模型一次过 + 1 美分；
- **Unstructured**：连接器矩阵 + 唯一 open-core + 唯一 FedRAMP；
- **Landing**：Ground 证据链 + 自研视觉模型；
- **Extend**：Verify 文档反欺诈 + 评测回归平台；
- **合合**：业务审核规则库 + 印章 / 手写抽取 + 中国文档形态 —— **这一层四家都没有对应物**。

***

**一句话收敛**：四家出身不同、去向相同，都在从「卖确定性工具」往「编排整条文档流程」迁；合合带着层一现金流做层二，两层同时在手，姿势比单押一个点的海外厂商更稳。

## 6. 技术简析（笔试题可选部分）

技术差异只需回答两个问题：自研的是不是大模型，以及它们怎么和大模型、Agent 结合。

### 6.1 自研的是不是大模型：五家都不是

五家都**不做** GPT、Gemini、Claude 那种通用大模型（百亿到万亿参数、训练成本上亿美元）。它们自研的是文档专用模型，且分两代：

- **第一代是一堆「小网络」**：OCR、版面、表格、手写各一个，参数通常在百万到几亿，每个只干一件窄事；
- **第二代是「中型端到端模型」**：Reducto r-1、Extend Parse 2.0、Landing DPT-3 属于这类，一个全页模型一次处理整页，参数大概在几十亿量级 —— 比通用大模型小一两个数量级，但比小网络大、且只在文档上专精。

**合合 xParse 的模型构成未公开**，从披露的能力开关、高级引擎配置、可追溯元数据看，更可能是「专用视觉模型 + 可选路由」，和 Extend、Reducto 的混合路线同类（具体参数不公开，不报死）。

### 6.2 怎么和大模型、Agent 结合：五种姿势

- **Reducto：用一个中型模型替代「多工具 + 大模型」的拼接**。r-1 一次出结果，把原来要 OCR、版面、VLM 串好几遍的管线收成一步；需要自定义提示或高级图表时，再叠加 agentic 增强。
- **Landing：自研视觉模型 + agentic 编排**。系统自己「规划、决策、校验，直到质量达标」，通用大模型不是它的起点，数据闭环才是。
- **Extend：最典型的「混合调度」**。自研专用小模型 + 直接调用前沿基础模型，按页面难度换引擎 —— 脏页走视觉模型、推理活交给大模型，成本和延迟可分档。
- **Unstructured：开源库做解析、模型当货架**。Auto / Fast / High-Res / VLM 四种策略按页自动换挡，分块、NER、OCR、图表描述、embedding 按需挑选，平台负责编排。
- **合合：xParse 开源生态 + DocFlow 闭源编排**。xParse 走开源（xparse-skills、textin-mcp），DocFlow 闭源、内置审核规则库，和海外「开源接口 + 闭源平台」是同款打法。

### 6.3 一个判断

文档 AI 的技术含量**不在模型大小**，而在「专用模型 + 通用大模型 + Agent 编排」三者的组合能力，以及真实文档数据、评测回归的闭环。比参数是最外行的比法，比「谁能在真实脏文档上稳定落地」才是关键。

## 7. 来源、方法与适用范围（「我怎么判断 AI 信息可信」）

### 7.1 六步判断法（本次全流程实测）



1. **只抓一手原文、留双标识**：官网 / 文档站 / 定价页直接抓正文，存 `reference/`，每文件头带 `> 来源: URL` + `> 抓取时间: 2026-10-27`。引用永远指向可回访的 URL。

2. **三类材料交叉验证**：官网宣称（营销层）↔ 功能文档（能力层）↔ 计价 / 部署结构（商业层）。三者一致才升格为结论；不一致以结构为准、宣称打低信任（AGENTS.md 约定 3）。例：Reducto 首页 5B+ vs 文档 3B+ → 数字不作结论，仅 \[待核]。

3. **营销词拆用法**：同一个词「agentic」拆成「输出给 Agent 吃」vs「系统自己变 Agent」两种用法，只用后者做层级判断（§5.2）。

4. **缺项本身是信息**：定价不公开 → 销售主导型企业模式的证据（Landing FAQ 原话自证）；有公开定价页 → PLG 定位证据（Unstructured 三档、Reducto 按量锚点）。不说「找不到 = 造假」，说「没找到 + 它意味着什么」。

5. **证据分级 + 弱证不当砖**：叙事 = 旁证、功能清单 = 印证、计价结构 = 地基，不同等级给不同结论强度，结论句里显式打标。

6. **写明适用范围**（见 7.2）。
